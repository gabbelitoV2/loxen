## Bluetooth LE central (BLE, package com.moblin.android.platform.corebluetooth)
- `CBCentralManager(delegate: self, queue: q)` -> `com.moblin.android.platform.corebluetooth.CBCentralManager(delegate = { central -> centralManagerDidUpdateState(central) }, queue = q)`, where `.main` is `null` and a dispatch queue is its `CoroutineScope`. `CBCentralManagerDelegate` is a `fun interface` with only `centralManagerDidUpdateState(central: CBCentralManager)`. Never call `BluetoothAdapter`, `BluetoothLeScanner` or `BluetoothDevice.connectGatt` yourself: the shim asks for the Bluetooth permission on first use like iOS and calls the delegate on every state change, so a Swift file never calls `centralManagerDidUpdateState` itself.
- `central.state` is a `CBManagerState` (`unknown` until the first delegate call, then `unsupported`, `unauthorized` until the permission is granted, `poweredOff`, `poweredOn`). `CBCentralManager.authorization == .allowedAlways` -> `CBCentralManager.authorization == CBManagerAuthorization.allowedAlways`. `centralManager = nil` -> `centralManager?.delegate = null; centralManager = null`.
- `central.scanForPeripherals(withServices: ids)` -> `central.scanForPeripherals(withServices = ids, callback = scanCallback)` with an `android.bluetooth.le.ScanCallback` (or `scanForPeripherals(filters, settings, callback)`); `stopScan()` keeps its shape. `didDiscover` is `onScanResult`, `CBAdvertisementDataLocalNameKey` is `result.scanRecord?.deviceName`.
- `peripheral.identifier` stays `peripheral.identifier` on the `BluetoothDevice` (`import com.moblin.android.platform.corebluetooth.identifier`): a `UUID` made from the Bluetooth address, so `identifier.uuidString` -> `identifier.toString()` and a saved `bluetoothPeripheralId` is compared with `it.identifier == deviceId`. Never use `address` or `UUID.nameUUIDFromBytes` as the id. `central.retrievePeripherals(withIdentifiers: [id]).first` -> `central.retrievePeripherals(withIdentifiers = listOf(id.toString())).firstOrNull()` (a `BluetoothDevice`, found from that identifier). `central.connect(peripheral, options: nil)` -> `gatt = central.connect(peripheral, callback = gattCallback)` (a `BluetoothGatt?`, null without permission); `central.cancelPeripheralConnection(p)` -> `central.cancelPeripheralConnection(gatt)`.
- Every other permission-protected call (`BluetoothGatt` `discoverServices`, `setCharacteristicNotification`, `writeDescriptor`, `writeCharacteristic`, `readCharacteristic`, `disconnect`, `close`, and `BluetoothDevice.name`) goes inside `com.moblin.android.platform.corebluetooth.bluetoothCall { ... }`, or `bluetoothCall(fallback) { ... }` when its value is used, which returns the fallback instead of throwing a SecurityException. The shim itself never throws.
