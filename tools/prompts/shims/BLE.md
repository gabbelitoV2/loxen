## Bluetooth LE central (BLE, package com.moblin.android.platform.corebluetooth)
- CoreBluetooth keeps its names: import `CBCentralManager`, `CBCentralManagerDelegate`, `CBManagerState`, `CBManagerAuthorization`, `CBPeripheral`, `CBPeripheralDelegate`, `CBPeripheralState`, `CBService`, `CBCharacteristic`, `CBDescriptor`, `CBUUID`, `CBCharacteristicWriteType`, `CBCharacteristicProperties`, `CBError`, `CBATTError` and the `CBAdvertisementData...Key`/`CBConnectPeripheralOption...` constants from `com.moblin.android.platform.corebluetooth`. Never use `android.bluetooth` (`BluetoothAdapter`, `BluetoothDevice`, `BluetoothGatt`, `BluetoothGattCallback`, `ScanCallback`, `ScanResult`) in a translated file. The shim asks for the permission like iOS, never throws a SecurityException, queues every GATT operation itself (Android allows one at a time), writes the notification descriptor for `setNotifyValue`, negotiates the MTU, leaves the GAP and GATT services (1800, 1801) out of `services` like iOS and scans for a saved device Android has forgotten (after a reboot) before connecting to it, so translate the Swift calls as they are: add no waits, retries, scans, descriptor writes, service filters or permission checks.
- A stored manager `private var centralManager: CBCentralManager?` -> `private var centralManager: CBCentralManager? by CBCentralManager.holder()`. Assigning `nil` or another manager releases the old one like ARC: its connections close, its scan stops and its delegates get no more calls, so `centralManager = nil` stays `centralManager = null` with nothing added. `CBCentralManager(delegate: self, queue: q)` -> `CBCentralManager(delegate = this, queue = q)`; `.main`, `DispatchQueue.main` and `nil` -> `queue = null`; a Swift `DispatchQueue` -> the `CoroutineScope` that stands in for it. Every central and peripheral delegate call runs on that queue, in order, after the call that caused it returns.
- Delegates: `extension X: CBCentralManagerDelegate`/`CBPeripheralDelegate` -> `class X : CBCentralManagerDelegate, CBPeripheralDelegate` with `override fun`s. Swift's overloaded selectors get these names (all but the first have empty defaults): `centralManagerDidUpdateState(central: CBCentralManager)`; `centralManager(_:didDiscover:advertisementData:rssi:)` -> `centralManagerDidDiscover(central: CBCentralManager, peripheral: CBPeripheral, advertisementData: Map<String, Any>, rssi: Int)`; `didConnect` -> `centralManagerDidConnect(central, peripheral)`; `didFailToConnect` -> `centralManagerDidFailToConnect(central, peripheral, error: Throwable?)`; `didDisconnectPeripheral:error:` -> `centralManagerDidDisconnectPeripheral(central, peripheral, error: Throwable?)`; `didDisconnectPeripheral:timestamp:isReconnecting:error:` -> `centralManagerDidDisconnectPeripheral(central, peripheral, timestamp: Double, isReconnecting: Boolean, error: Throwable?)`, called instead of the short one when overridden. `peripheral(_:didDiscoverServices:)` -> `peripheralDidDiscoverServices(peripheral: CBPeripheral, error: Throwable?)`; `didDiscoverCharacteristicsFor` -> `peripheralDidDiscoverCharacteristicsFor(peripheral, service: CBService, error)`; `didDiscoverDescriptorsFor` -> `peripheralDidDiscoverDescriptorsFor(peripheral, characteristic: CBCharacteristic, error)`; `didUpdateValueFor` -> `peripheralDidUpdateValueFor(peripheral, characteristic: CBCharacteristic, error)` (also a `descriptor: CBDescriptor` overload); `didWriteValueFor` -> `peripheralDidWriteValueFor(peripheral, characteristic, error)`; `didUpdateNotificationStateFor` -> `peripheralDidUpdateNotificationStateFor(peripheral, characteristic, error)`; `didReadRSSI` -> `peripheralDidReadRSSI(peripheral, rssi: Int, error)`; `peripheralIsReady(toSendWriteWithoutResponse:)` -> `peripheralIsReadyToSendWriteWithoutResponse(peripheral)`; `didModifyServices` -> `peripheralDidModifyServices(peripheral, invalidatedServices: List<CBService>)`. A Swift `_` parameter gets a name; when the body uses a stored property with that name (`peripheral?.setNotifyValue` with `_: CBPeripheral`), name the parameter differently. Model's extension delegate stays a lambda: `CBCentralManager(delegate = { centralManagerDidUpdateState(it) }, queue = null)`.
- Central calls keep their labels: `central.state` (`unknown` until the first `centralManagerDidUpdateState`, then `unsupported`, `unauthorized` until the permission is granted, `poweredOff`, `poweredOn`); `CBCentralManager.authorization == .allowedAlways` -> `CBCentralManager.authorization == CBManagerAuthorization.allowedAlways`; `central.scanForPeripherals(withServices: ids)` -> `central.scanForPeripherals(withServices = ids)` (`List<CBUUID>?`, optional `options = mapOf(CBCentralManagerScanOptionAllowDuplicatesKey to true)`); `stopScan()`, `isScanning`; `central.retrievePeripherals(withIdentifiers: [id]).first` -> `central.retrievePeripherals(withIdentifiers = listOf(id)).firstOrNull()` (`java.util.UUID` ids, the same `CBPeripheral` object every time); `central.connect(p, options: nil)` -> `central.connect(p)`, with `options = mapOf(CBConnectPeripheralOptionEnableAutoReconnect to true)` for that option; `central.cancelPeripheralConnection(p)` keeps its shape. As on iOS a connect never times out; it ends with `didConnect`, `didFailToConnect` or a cancel.
- `CBPeripheral`: `identifier` (`UUID`, `identifier.uuidString` -> `identifier.toString()`), `name` (`String?`), `state` (`CBPeripheralState`), `delegate` (`peripheral.delegate = self` -> `peripheral.delegate = this`), `services` (`List<CBService>?`), `canSendWriteWithoutResponse`; `==` compares identifiers. `peripheral.discoverServices(nil)` -> `peripheral.discoverServices(null)`; `discoverCharacteristics(ids, for: s)` -> ``discoverCharacteristics(ids, `for` = s)``; ``discoverDescriptors(`for` = c)``; `readValue(for: c)` -> ``readValue(`for` = c)``; `writeValue(d, for: c, type: .withoutResponse)` -> ``writeValue(d, `for` = c, type = CBCharacteristicWriteType.withoutResponse)``; `setNotifyValue(true, for: c)` -> ``setNotifyValue(true, `for` = c)``; `maximumWriteValueLength(for: .withoutResponse)` -> ``maximumWriteValueLength(`for` = CBCharacteristicWriteType.withoutResponse)`` (`Int`); `readRSSI()`.
- Attributes: `service.characteristics ?? []` -> `service.characteristics.orEmpty()`; `characteristic.value` is `ByteArray?`, `characteristic.uuid` a `CBUUID`, plus `isNotifying`, `service`, `descriptors` and `properties` (`properties.contains(.notify)` -> `properties.contains(CBCharacteristicProperties.notify)`). `CBUUID(string: "180D")` -> `CBUUID(string = "180D")`, `CBUUID(data: d)` -> `CBUUID(data = d)`, `CBUUID(nsuuid: u)` -> `CBUUID(nsuuid = u)`, `uuid.uuidString` keeps its shape. 16-bit and full forms are equal, so `switch characteristic.uuid { case id: }` -> `when (characteristic.uuid) { id -> }` and `Set<CBUUID>`/`[CBUUID: T]` keep their shape; never convert to `java.util.UUID`.
- `advertisementData[CBAdvertisementDataLocalNameKey] as? String`, `advertisementData[CBAdvertisementDataManufacturerDataKey] as? Data` -> `as? ByteArray` (company id first, as on iOS); `CBAdvertisementDataServiceUUIDsKey` is a `List<CBUUID>`, `CBAdvertisementDataServiceDataKey` a `Map<CBUUID, ByteArray>`, `CBAdvertisementDataTxPowerLevelKey` an `Int`, `CBAdvertisementDataIsConnectable` a `Boolean`. `rssi: NSNumber` is an `Int`. `error == nil` -> `error == null`; `error as? CBATTError` with `.code == CBATTError.Code.insufficientAuthentication`, `CBError` with `CBError.Code`.
- A scanner is an `ObservableObject` but not a settings class, so `@Published var discoveredDevices: [T] = []` -> `val discoveredDevices = MutableStateFlow<List<T>>(emptyList())`, never `Published` or `PublishedList`: `discoveredDevices = []` -> `discoveredDevices.value = emptyList()`, `discoveredDevices.append(x)` -> `discoveredDevices.value = discoveredDevices.value + x`, other reads go through `discoveredDevices.value`.
- `data.hexString()` (Common's `Data` extension) -> `data.hexString()` with `import com.moblin.android.common.various.hexString`; never `TODO()` or a hand-written hex loop.
- Device protocol files: a top-level `nonisolated(unsafe) let xId = CBUUID(string: "2A37")` -> `val xId = CBUUID(string = "2A37")`. Service and characteristic ids, stored attributes (`var c: CBCharacteristic?`) and the ids given to `BluetoothScanner(serviceIds = ids)` (no context argument) stay `CBUUID`/`CBCharacteristic`: never `java.util.UUID`, `UUID.fromString`, `CBUUID(nsuuid = ...)` around an id or the shim's internal `.characteristic`. `flags.isBitSet(index: i)` -> `flags.isBitSet(index = i)` from com.moblin.android.common.various (UByte, UShort, UInt, ULong); UByte and UShort have no `shr`, so `(b & m) >> n` -> `((b and m).toInt() shr n).toUByte()`. `ContinuousClock.now`/`ContinuousClock.Instant` -> the same names from com.moblin.android.platform.core: `a.duration(to: b) > .seconds(3)` -> `a.duration(to = b) > 3.seconds`, a duration's `.seconds` -> `.toDouble(DurationUnit.SECONDS)`, never java.time.Instant or SystemClock.
- Device settings views: the Model helpers they call (`model.enableWorkoutDevice(device:)`, `isWorkoutDeviceEnabled`, `setCurrentWorkoutDevice`, ...) are `fun Model.x` extension functions in com.moblin.android.various.model, so import each one called (`import com.moblin.android.various.model.enableWorkoutDevice`). `SettingsWorkoutDevices.devices` is a `PublishedList` mutated in place: `workoutDevices.devices.append(d)` -> `workoutDevices.devices.add(d)`, `removeAll { }` keeps its shape and `remove(atOffsets: o)` -> `remove(atOffsets = o)` with `import com.moblin.android.platform.swiftui.remove`; other device lists keep the type Settings declares for them. `keyboardType: .numbersAndPunctuation` -> `keyboardType = KeyboardType.Number` (androidx.compose.ui.text.input.KeyboardType). `@ObservedObject private var scanner = xScanner` -> `val scanner = xScanner` plus `val discoveredPeripherals by scanner.discoveredPeripherals.collectAsState()` where the body reads it, and `scanner.discoveredPeripherals.value` in callbacks.
- `Model.bluetoothAllowed` is a `MutableStateFlow<Boolean>`: in `extension Model` (ModelBluetooth) `bluetoothAllowed = CBCentralManager.authorization == .allowedAlways` -> `fun Model.centralManagerDidUpdateState(central: CBCentralManager) { bluetoothAllowed.value = CBCentralManager.authorization == CBManagerAuthorization.allowedAlways }`, and views read it with `val bluetoothAllowed by model.bluetoothAllowed.collectAsState()`. `BluetoothScanner` and `TeslaVehicleScanner` are non-final Swift classes: `open class` with `open val discoveredPeripherals` and `open fun`s; `static let shared = X()` -> `companion object { val shared by lazy { X() } }`, read as `X.shared`.
- Scanner settings views: `Text` is `androidx.compose.material3.Text` (there is no `com.moblin.android.platform.swiftui.Text`); `@Environment(\.dismiss) var dismiss` -> `val dismiss = rememberDismiss()` (com.moblin.android.platform.swiftui), so the view takes no dismiss parameter; `.onAppear { scanner.startScanningForDevices() }` plus `.onDisappear { scanner.stopScanningForDevices() }` -> `DisposableEffect(Unit) { scanner.startScanningForDevices(); onDispose { scanner.stopScanningForDevices() } }`; `peripheral.identifier.uuidString` -> `peripheral.identifier.toString()` with no extra import, since `identifier` is a `CBPeripheral` member.
