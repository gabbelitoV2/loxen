## Network paths, listeners, SRTLA and NTP (T9, packages com.moblin.android.platform.network and com.moblin.android.platform.ntp)

- `NWPathMonitor()` and `NWPathMonitor(requiredInterfaceType: t)` -> `NWPathMonitor()` and `NWPathMonitor(requiredInterfaceType = t)` from `com.moblin.android.platform.network`. `pathUpdateHandler = f` (a method reference `::f` or `this@Class::f` inside a lambda, taking an `NWPath`), `start(queue = q)` with the `CoroutineDispatcher` of the Swift queue, `cancel()` and `currentPath` keep their names. It holds a `ConnectivityManager.requestNetwork` per transport, so cellular stays up while Wi-Fi is the default; never use `ConnectivityManager`, `NetworkCallback` or `android.net.Network` for a Swift `NWPathMonitor` or `NWInterface`.
- `NWPath` from `com.moblin.android.platform.network`: `status` (`NWPath.Status.satisfied`, `.unsatisfied`, `.requiresConnection`), `availableInterfaces: List<NWInterface>`, `usesInterfaceType(t)`, `isExpensive`, `isConstrained`, and `uniqueAvailableInterfaces()` as a member; never declare that extension. `NWInterface` values compare by `name` and `type`; `NWInterface.InterfaceType.other` exists.
- `try NWListener(using: params)` and `try NWListener(using: params, on: port)` -> `NWListener(using = params)` and `NWListener(using = params, on = port)`; the constructor never throws. UDP (`NWParameters.udp`, `NWParameters.dtls(null)`) and plain TCP only, no TLS and no `service` (Bonjour). `acceptLocalOnly = true` binds 127.0.0.1. `stateUpdateHandler`, `newConnectionHandler` (gets an `NWConnection` to `start(queue = q)`), `start(queue = q)`, `cancel()` and `port` (`NWEndpoint.Port?`; `listener.port!.rawValue` -> `listener.port!!.value` as an `Int`) keep their names. `NWListener.State`: `.setup`, `.ready` and `.cancelled` are objects; `.waiting` and `.failed` are classes with `error`, as for `NWConnection.State`.
- `srtlaClientQueue` stays `val srtlaClientQueue: CoroutineDispatcher` in `SrtlaClient.kt`; other files wrap it. `srtlaClientQueue.async { }` -> `CoroutineScope(srtlaClientQueue).launch { }`, `srtlaClientQueue.sync { x }` -> `runBlocking(srtlaClientQueue) { x }`. A blocking call (DNS) inside it runs in `withContext` on another executor.
- In the SRTLA client, `UInt16` ports (`SrtlaDelegate.srtlaReady`, `moblinkStreamerDestinationAddress`, `LocalListener.onReady`) are `Int`, and `SrtlaClient.addMoblink(endpoint:id:name:)`/`removeMoblink(endpoint:)` take `host: String, port: Int` instead of an `NWEndpoint`. `ContinuousClock.now` is `System.nanoTime()` and durations are nanosecond `Long`s. `Data.random(length: n)` -> `kotlin.random.Random.nextBytes(n)`.
- `TrueTimeClient.sharedInstance` -> `com.moblin.android.platform.ntp.TrueTimeClient.sharedInstance` with `start(pool = listOf(host))`, `pause()` and `referenceTime?.now()`, a `java.time.Instant`; `.now().timeIntervalSince1970` -> `.now().toEpochMilli() / 1000.0`.
