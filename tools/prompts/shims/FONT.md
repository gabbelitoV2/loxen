## Installed fonts (FONT, packages com.moblin.android.platform.uikit and .coretext)
- `UIFont.familyNames` -> `UIFont.familyNames` (import com.moblin.android.platform.uikit.UIFont), a `List<String>` of the installed families; `Set(UIFont.familyNames)` -> `UIFont.familyNames.toMutableSet()`. `UIFont.fontNames(forFamilyName: f)` -> `UIFont.fontNames(forFamilyName = f)`, the PostScript names of the family's faces, regular first, empty for an unknown family. Never TODO them or return an empty list.
- CoreText keeps its C names, imported from com.moblin.android.platform.coretext: `CTFontCollectionCreateFromAvailableFonts(nil)` -> `CTFontCollectionCreateFromAvailableFonts(null)`; `CTFontCollectionCreateMatchingFontDescriptors(c) as? [CTFontDescriptor]` -> `CTFontCollectionCreateMatchingFontDescriptors(c)`, already a `List<CTFontDescriptor>?`, so no cast; `CTFontDescriptorCopyAttribute(d, kCTFontFamilyNameAttribute) as? String` -> the same call with `as? String`.
- `UIFont(name: n, size: s)` -> `UIFont(name = n, size = s)`, null when no installed face has that PostScript, full or family name. Where the Kotlin draws with android.graphics.Typeface, use its `typeface`: `if let font = UIFont(name: n, size: s) { return font }` -> `UIFont(name = n, size = s)?.let { return it.typeface }`, and `UIFont(descriptor: UIFontDescriptor(fontAttributes: [.family: f]), size: s)` -> `UIFont(name = f, size = s)?.typeface ?: Typeface.DEFAULT`.
- `.font(.custom(n, size: s))` -> `style = SwiftUIFonts.custom(name = n, size = s)` (com.moblin.android.platform.swiftui), which draws the installed face or family n names.
- `@Binding var font: SettingsFont` -> `font: MutableState<SettingsFont>` (callers pass `binding(get, set)`). SettingsFont is an immutable data class: `font = SettingsFont(...)` -> `font.value = SettingsFont(...)`, `font.style = s` -> `font.value = font.value.copy(style = s)`, reads go through `font.value`.
- A List row `HStack { Text(t); Spacer(); Button { a() } label: { if selected { Image(systemName: "checkmark") } } }` -> `FormRow(onClick = { a() }) { Text(t); Spacer(Modifier.weight(1f)); if (selected) { SystemImage(name = "checkmark", fontSize = 17.sp, tint = formPalette().accent) } }` with SystemImage from com.moblin.android.platform, because iOS makes the whole row the button and a Button inside a FormRow is only as large as its label.
