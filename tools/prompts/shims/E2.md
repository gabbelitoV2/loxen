## Offscreen view rendering and Combine (E2, packages com.moblin.android.platform.swiftui, .combine and .uikit)
- `ImageRenderer(content: V(a: x, b: y))` -> copy every argument into a local val first, then `ImageRenderer(content = { V(a = x0, b = y0) })`; the lambda captures only those locals, never `this`. The type `ImageRenderer<V>` -> `ImageRenderer` (not generic). `renderer.cgImage`/`renderer.uiImage` -> the same (Bitmap?, main thread). `renderer.objectWillChange.sink { ... }` -> `renderer.objectWillChange.sink { ... }`, which returns `AnyCancellable` (platform.combine); store it in `AnyCancellable?`, never launch a coroutine for it; `.store(in: &set)` -> `.store(into = set)`. `renderer.scale` (Float), `proposedSize` (`ProposedViewSize(width = w, height = h)`, `.unspecified`), `isOpaque` keep their names.
- Published values are Kotlin StateFlows: `x.$y.sink { v in ... }` -> `x.y.sink { v -> ... }` (platform.combine, returns AnyCancellable, delivers the current value first like Combine); `.dropFirst()` -> `.dropFirst()`. `[AnyCancellable]` -> `MutableList<AnyCancellable>`; `cancellables = []` -> cancel each, then clear. `{ [weak self] ... self?.f() }` in a sink -> `val weakSelf = java.lang.ref.WeakReference(this)` before the call and `{ weakSelf.get()?.f() }`; never capture `this`.
- `post.state.objectWillChange.sink` (ChatPostState) -> `post.state.deleted.dropFirst().sink { ... }`.
- In views rendered to images: `.font(.system(size: s, weight: w, design: d))` -> `SwiftUIFonts.system(s, w, d)` as the TextStyle; `.font(.custom(n, size: s))` -> `SwiftUIFonts.custom(n, s)`; `.monospacedDigit()` -> `style.monospacedDigit()`; `Font.Design` and `UIFontDescriptor.SystemDesign` -> `com.moblin.android.view.utils.FontDesign` (`.monospaced` -> `FontDesign.Monospaced`); never declare a FontDesign enum. `UIImage(systemName: n) != nil` -> `hasSystemImage(n)`. Swift Charts `Chart(data) { item in SectorMark(angle: .value("", item.w)).foregroundStyle(c) }` -> `Chart(data) { item -> SectorMark(angle = item.w.toDouble(), foregroundStyle = c) }`.
- Views rendered to images get SwiftUI's defaults from `ImageRenderer`: a `Text` without a font is `SwiftUIFonts.system(17f)` in black, so never add a Material theme or a default style, and never use `rememberGraphicsLayer()`/`layer.record` there (they cannot draw into the software canvas). `.lineLimit(1).minimumScaleFactor(f)` -> a scale state remembered with the text and the base size as keys; in `onTextLayout`, while `result.hasVisualOverflow` and the scale is above `f`, set it to `maxOf(f, scale * result.size.width / result.multiParagraph.intrinsics.maxIntrinsicWidth)`, which lands on SwiftUI's exact fit within two passes (with `.lineLimit(n)` for n > 1, shrink by 2 % per pass instead); `cgImage` runs the pending recompositions and layouts before it draws, so one read returns the settled size.
- UIKit drawing: `UIGraphicsImageRendererFormat()`, `format.scale`, `format.opaque`, `UIGraphicsImageRenderer(size:format:).image { context in ... }` keep their shape; `context.cgContext` is an android.graphics.Canvas; `view.layer.render(in: context.cgContext)` -> `view.draw(context.cgContext)`; `view.frame = r` -> `view.frame = r` (extension that measures and lays out); `layoutIfNeeded()` and `layer.displayIfNeeded()` on a generated view -> drop. `UIView()` -> `UIView()` (platform.uikit); `uiView.backgroundColor = .clear` -> `uiView.backgroundColor = Color.Transparent`; `ChatLineUiView()` -> `ChatLineUiView(AppDelegate.context)`, and its `size(availableWidth:)` returns a Compose IntSize (convert with `CGSize(width = s.width, height = s.height)`). `CALayer()`, `layer.addSublayer`, `removeFromSuperlayer`, `CALayer.frame`, `backgroundColor = UIColor(c).cgColor` -> `backgroundColor = CGColor(color = c)`.
- UIImage and CGImage are android.graphics.Bitmap; `image.cgImage` stays (identity extension); `UIImage(cgImage: b)` -> `b`; `UIImage(data: d)` -> `UIImage(data = d)` and `UIImage(contentsOfFile: p)` -> `UIImage(contentsOfFile = p)` (platform.uikit, Bitmap?); `image.size` -> `image.size` (CGSize), `image.scale` -> `image.scale` (1.0).
