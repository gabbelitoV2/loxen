## libsrt (T10, package com.moblin.android.platform.srt)

- `import libsrt` -> `import com.moblin.android.platform.srt.SrtNative` (plus `SrtSendHook` when used). Call every libsrt function and constant by its C name on `SrtNative` (`SrtNative.srt_close(s)`, `SrtNative.SRTO_STREAMID`); never declare `SrtNative`, `external` functions, `System.loadLibrary`, private `srt_*` stubs or local SRT constants.
- `SRTSOCKET` and `SRT_SOCKOPT` -> `Int` (same-named typealiases exist in the package). `SRT_INVALID_SOCK`, `SRT_ERROR`, `SRTO_*`, `SRTT_*`, `SRTS_*` and `SRT_E*` are `Int` constants: drop `.rawValue`, and `SRT_SOCKOPT(rawValue: n)` -> `n`. Every function returns `Int` and never throws.
- `sockaddr_in` built by hand or with `gethostbyname`/`inet_addr`, then passed through `withUnsafePointer`/`withMemoryRebound` with `MemoryLayout.size(ofValue:)` -> `val addr = SrtNative.sockaddrIn(host, port)` (16-byte `ByteArray`, IPv4 only, blocking DNS) and `SrtNative.srt_connect(s, addr, addr.size)` or `SrtNative.srt_bind(s, addr, addr.size)`.
- Buffers behind `withUnsafeBytes`/`withUnsafeMutableBytes` or `[CChar]` -> the `ByteArray` itself: `srt_setsockopt(s, 0, opt, bytes, bytes.size)`, `srt_sendmsg2(s, bytes, count)` (the `nil` mctrl is dropped), `srt_recvmsg(s, bytes, bytes.size)` fills `bytes` and returns the count. `srt_accept(s, nil, nil)` -> `srt_accept(s)`; `srt_getlasterror(nil)` -> `srt_getlasterror(null)`.
- `srt_getsockflag(s, opt, &int32Value, &size)` -> `val value = IntArray(1); val size = intArrayOf(4); SrtNative.srt_getsockflag(s, opt, value, size)`; for strings pass a `ByteArray` and `intArrayOf(capacity)`.
- `srt_bstats(s, &perf, clear)` -> `SrtNative.srt_bstats(s, perf, clear)` with `perf: CBytePerfMon`, the data class in `com.moblin.android.media.haishinkit.srt` (keep it declared in `SrtPerformanceData.kt`).
- `srt_send_callback(s, { context, _, buf1, size1, buf2, size2 in ... }, context)` -> `SrtNative.srt_send_callback(s, SrtSendHook { packet -> ... })`: `packet` is `buf1` and `buf2` joined, return `true` when sent. The null checks and the size arithmetic are done natively, and `srt_close` releases the hook.
- `srt_getlasterror_str()` and `srt_rejectreason_str(r)` return a non-null `String`; `String(cString:)` around them is dropped.
- A thrown `String` in a file that imports libsrt (`throw makeSocketError()`, `throw "Bind failed: ..."`) -> `throw SrtError(message)` from the same package, an `IOException` whose `toString()` is the message, so `"\(error)"` -> `"$error"` prints the same text.
