## Cat printer and Black Shark cooler (CPBS, packages com.moblin.android.platform.blacksharklib, com.moblin.android.platform.core and com.moblin.android.platform.swiftui)
- The Swift package BlackSharkLib -> `com.moblin.android.platform.blacksharklib.BlackSharkLib`, an `object` with the same static functions (`import BlackSharkLib` -> that import); never redeclare it or any of its types. `BlackSharkLib.Model` is an enum with `pro4` and `pro5` (`.pro5` -> `BlackSharkLib.Model.pro5`). `parseMessages(value)` returns a `BlackSharkLib.Message` (`rawData: ByteArray`), so `if let s = message as? BlackSharkLib.CoolingState` -> `if (message is BlackSharkLib.CoolingState)`; `CoolingState` has `phoneTemperature`, `heatsinkTemperature` (`Int`), `fanRPM` and `powerLevel` (`Int?`). `getReadCharacteristicsUUID()`/`getWriteCharacteristicsUUID()` return the 2-byte `ByteArray`, so `CBUUID(data: BlackSharkLib.getReadCharacteristicsUUID())` -> `CBUUID(data = BlackSharkLib.getReadCharacteristicsUUID())`; `getServiceUUID()` is a `java.util.UUID` (`getServiceUUID().uuidString` -> `getServiceUUID().toString()`). Labels stay: `detectModel(advertisedName = n)`, `getCoolingMetadataCommand(model = m)`, `getSetCoolingPowerCommand(p, model = m)`, `getSetFanSpeedCommand(p, model = m)`, `getSetCoolingEnabledCommand(b, model = m)`, `getSetCustomModeCommand(intensity = i, model = m)`, `getSetLEDColorCommand(r, g, b, brightness = x, model = m)`, `getTurnOffLEDCommand(model = m)`; the optional results keep Swift's `!` as `!!`.
- `ProcessInfo.processInfo.thermalState` -> `ProcessInfo.processInfo.thermalState` from `com.moblin.android.platform.core`, a `ProcessInfo.ThermalState` (`nominal`, `fair`, `serious`, `critical`); a `ProcessInfo.ThermalState` parameter keeps that type and `@unknown default:` -> `else ->`.
- `ContinuousClock.now` -> `ContinuousClock.now` from `com.moblin.android.platform.core`; `a.duration(to: b)` is a `kotlin.time.Duration`, so `>= .milliseconds(80)` -> `>= 80.milliseconds` with `import kotlin.time.Duration.Companion.milliseconds`.
- Moblin's `CIImage.scaled(x:y:)` (VideoEffects/EffectUtils.swift) is the extension `com.moblin.android.videoeffects.scaled(x: Double, y: Double)`: `let s = CGFloat(n) / image.extent.width` -> `val s = n.toDouble() / image.extent.width` (`extent` is a `CGRect` of `Double`s), then `image.scaled(x = s, y = s)`.
- `ColorPicker("Color", selection: $x.color, supportsOpacity: false)` with `.onChange(of: x.color) { body }` -> `ColorPicker(title = "Color", selection = x.color, onSelectionChange = { x.color = it; body }, supportsOpacity = false)` from `com.moblin.android.platform.swiftui`; Moblin's `color.toStandardRgb()` is `com.moblin.android.common.various.toStandardRgb` (an `RgbColor?`).
- `ByteReader.readUInt8()` returns a `UByte`: `reader.readUInt8() == 0x51` -> `reader.readUInt8() == 0x51.toUByte()`, `ok == 0` -> `ok == 0.toUByte()`; a bare `0x51u` literal is a `UInt` and does not compile against a `UByte`.
- `model.blackSharkCoolerDevices` is a plain `MutableMap<UUID, BlackSharkCoolerDevice>` (no `.value`). `SettingsBlackSharkCoolerDevice` has plain `var`s: `name`, `enabled`, `bluetoothPeripheralId: UUID?`, `bluetoothPeripheralName: String?`, `rgbLightEnabled`, `rgbLightColor: RgbColor`, `rgbLightColorColor: Color` and `rgbLightBrightness: Double`, so `Slider(value: $d.rgbLightBrightness, in: 0 ... 100)` -> `FormSlider(value = d.rgbLightBrightness.toFloat(), onValueChange = { d.rgbLightBrightness = it.toDouble() }, valueRange = 0f..100f)`.
- These device lists are not PublishedLists (the workout rule above does not apply): `SettingsBlackSharkCoolerDevices.devices` is a read-only `var devices: List<SettingsBlackSharkCoolerDevice>`, so `devices.append(d)` -> `devices = devices + d`, `devices.remove(atOffsets: o)` -> `devices = devices.removing(atOffsets = o)` (`com.moblin.android.platform.swiftui.removing`), `devices.removeAll { c }` -> `devices = devices.filterNot { c }`. `SettingsCatPrinters.devices` and `backgroundPrinting` are `MutableStateFlow`s (`catPrinters.devices.value = catPrinters.devices.value + d`), and so are `SettingsCatPrinter.enabled`, `bluetoothPeripheralId` (`UUID?`), `bluetoothPeripheralName`, `printChat`, `printSnapshots`, `printTwitch`, `printKick` and `faxMeowSound` (read with `collectAsState()`, write `.value`); its `name` is a plain `var`.
- `localized`, `LocalModel` and `LocalOnNavigate` are in package `com.moblin.android` (never `com.moblin.android.platform`); `GrayTextView` is `com.moblin.android.view.settings.streams.stream.GrayTextView`; `CatPrinter.start(deviceId:)` takes a `UUID?`.
- A class with a non-private `var state` and a Swift `func setState(state:)` (CatPrinter's `CurrentJob`) clashes with the property's JVM setter: keep both names and write `@JvmName("updateState") fun setState(state: JobState)`.
