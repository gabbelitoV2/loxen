## Scoreboard, bingo, pomodoro, poll and wheel of luck (E6)
- `init(canvasSize: CGSize)` of ScoreboardEffect, BingoCardEffect, PomodoroTimerEffect, PollEffect and WheelOfLuckEffect -> the constructor parameter `canvasSize: androidx.compose.ui.geometry.Size` (ModelScene passes a Compose Size), converted once inside with `canvasSize.toCGSize()`; the rest of the class and its views keep Swift's CGSize maths (`canvasSize.minimum()`, `canvasSize.width / 1920`).
- The SwiftUI views in these files are not Compose. They use the SwiftUI layout DSL in `com.moblin.android.platform.swiftui.layout`, which reproduces SwiftUI's layout (stack spacing, spacers, frames, stack re-proposal, text fitting) and drawing; this replaces the E2 rules for views rendered to images. Never use Compose Row, Column, Box, Text, Modifier or CompositionLocal in these views.
- `struct V: View { ...; var body: some View { X } }` -> `fun ViewBuilder.V(params): View = X` (`private struct` -> `private fun`; a body with `let`s -> a block body ending in `return X`; `@ObservedObject var s: T` -> a plain parameter `s: T`). A `@ViewBuilder` helper that can produce no view or several views -> `fun ViewBuilder.f(...)` returning Unit. Private helpers that read `modular`/`config`/`scale` live as `ViewBuilder` member extensions of a private class holding them.
- `ImageRenderer(content: V(a: x))` -> copy arguments to locals as E2 says, then `ImageRenderer(content = { SwiftUIView { V(a = x0) } })`; `setScoreboardImage(image: ImageRenderer(content: content).cgImage)` is a one-shot renderer, never stored and without a sink. Bingo, pomodoro and poll keep one renderer each with `objectWillChange.sink` (E2 rules).
- Containers keep Swift's shape: `VStack(alignment: .leading, spacing: 0) { }` -> `VStack(alignment = HorizontalAlignment.leading, spacing = 0.0) { }`; `HStack(alignment: .top, spacing: 6 * scale)` -> `HStack(alignment = VerticalAlignment.top, spacing = 6 * scale)`; `ZStack(alignment: .leading)` -> `ZStack(alignment = Alignment.leading)`; `Spacer()` -> `Spacer()` (never add a minLength), `Spacer(minLength: 0)` -> `Spacer(minLength = 0.0)`; `ForEach(xs) { x in ... }` and `ForEach(0 ..< n, id: \.self)` -> `for` loops inside the builder, and a modifier on the ForEach applies to each element; `if`/`else` stay; `Group { a }.m()` -> `a.m()`; `HCenter { c }` -> a private `fun ViewBuilder.HCenter(content: ViewBuilder.() -> Unit): View = HStack { Spacer(); content(); Spacer() }`.
- Leaves: `Text(s)`; `Image("Name")` -> `Image("Name")`; `Image(systemName: n)` -> `Image(systemName = n)`; a Color used as a view, `Color.black.opacity(0.25)` -> `ColorView(Color.Black.copy(alpha = 0.25f))`; `Rectangle()`, `RoundedRectangle(cornerRadius: r)` and `Circle()` keep their names, with `.fill(c)` and `.stroke(c, lineWidth = w)`; Swift Charts `Chart(data) { item in SectorMark(angle: .value("", item.w)).foregroundStyle(c) }` -> `Chart(data) { item -> SectorMark(angle = item.w.toDouble(), foregroundStyle = c) }`.
- Modifiers keep Swift's names and order; never reverse or merge them: `.padding(5 * scale)`, `.padding(.horizontal, x)` -> `.padding(EdgeSet.horizontal, x)`, `.padding([.horizontal, .bottom], x)` -> `.padding(EdgeSet.horizontal + EdgeSet.bottom, x)`, `.frame(width: w, height: h)` -> `.frame(width = w, height = h)`, `.frame(maxWidth: .infinity, alignment: .leading)` -> `.frame(maxWidth = Double.POSITIVE_INFINITY, alignment = Alignment.leading)`, `.background(c)`, `.overlay(Rectangle().stroke(c, lineWidth: 0.5))` -> `.overlay(Rectangle().stroke(c, lineWidth = 0.5))`, `.clipShape(RoundedRectangle(cornerRadius: r))` -> `.clipShape(RoundedRectangle(cornerRadius = r))`, `.cornerRadius(r)`, `.font(.system(size: s, weight: w, design: d))` -> `.font(Font.system(size = s, weight = w, design = d))` (`Font` from the DSL package, `w` a Compose FontWeight, `d` a FontDesign), `.fontDesign(.monospaced)` -> `.fontDesign(FontDesign.Monospaced)`, `.bold()`, `.bold(flag)`, `.monospacedDigit()`, `.foregroundStyle(c)`, `.lineLimit(n)`, `.minimumScaleFactor(f)`, `.multilineTextAlignment(.center)` -> `.multilineTextAlignment(TextAlignment.center)`, `.opacity(x)`, `.offset(x: a)` -> `.offset(x = a)`, `.rotationEffect(.degrees(a))` -> `.rotationEffect(Angle.degrees(a))`, `.resizable()`, `.scaledToFit()`. All lengths are Double.
- `c.opacity(x)` on a Color value -> `c.copy(alpha = c.alpha * x)`. SwiftUI named colours are the iOS system colours (light): `.blue` -> `Color(0xFF007AFF)`, `.red` -> `Color(0xFFFF3B30)`, `.yellow` -> `Color(0xFFFFCC00)`, `.green` -> `Color(0xFF34C759)`, `.pink` -> `Color(0xFFFF2D55)`, `.cyan` -> `Color(0xFF32ADE6)`, `.gray` -> `Color(0xFF8E8E93)`; never Compose `Color.Blue` and the like. `.black`, `.white` and `.clear` -> `Color.Black`, `Color.White` and `Color.Transparent`.
- `String(format: "%02d:%02d", a, b)` -> `String.format(Locale.US, "%02d:%02d", a, b)` (Swift formats without a locale, so digits stay ASCII).
- A private `ObservableObject` with `@Published var x` that a view reads -> a class with `var x: T by Published(v)` (com.moblin.android.platform.swiftui.Published), read directly inside the builder.
- In `renderer.objectWillChange.sink { [weak self] in … }` read every member through the weak reference (`weakSelf.get()?.let { self -> self.setTimerImage(image = self.renderer?.cgImage) }`); a bare `renderer` in the lambda is `this.renderer` and keeps the effect alive.
