## Scoreboard, bingo, pomodoro, poll and wheel of luck (E6)
- `init(canvasSize: CGSize)` of ScoreboardEffect, BingoCardEffect, PomodoroTimerEffect, PollEffect and WheelOfLuckEffect -> the constructor parameter `canvasSize: androidx.compose.ui.geometry.Size` (ModelScene passes a Compose Size), converted once inside with `canvasSize.toCGSize()`; the rest of the class and its views keep Swift's CGSize maths (`canvasSize.minimum()`, `canvasSize.width / 1920`).
- `setScoreboardImage(image: ImageRenderer(content: content).cgImage)` -> `setScoreboardImage(image = ImageRenderer(content = content).cgImage)`: a one-shot renderer, never stored and without a sink. Bingo, pomodoro and poll keep one renderer each with `objectWillChange.sink` (E2 rules). The views stay private @Composable functions.
- `Image("VolleyballIndicator")` -> `AssetImage(name = "VolleyballIndicator", modifier = …)` (com.moblin.android.platform.swiftui). `.minimumScaleFactor(f)` on a Text -> a Text whose `onTextLayout` lowers the font size while `hasVisualOverflow`, down to `f` times the size.
- In `renderer.objectWillChange.sink { [weak self] in … }` read every member through the weak reference (`weakSelf.get()?.let { self -> self.setTimerImage(image = self.renderer?.cgImage) }`); a bare `renderer` in the lambda is `this.renderer` and keeps the effect alive.
- SwiftUI modifiers apply from the inside out, so reverse the chain: `.offset(x: o).rotationEffect(a).frame(width: w)` -> `Modifier.width(w.dp).rotate(a).offset(x = o.dp)`. Content inside `.frame(width:height:)` is centred: a Row gets `horizontalArrangement = Arrangement.Center`, a Text of fixed width `textAlign = TextAlign.Center`, a Text of fixed height a trailing `.wrapContentSize()`.
- SwiftUI named colours are the iOS system colours (light): `.blue` -> `Color(0xFF007AFF)`, `.red` -> `Color(0xFFFF3B30)`, `.yellow` -> `Color(0xFFFFCC00)`, `.green` -> `Color(0xFF34C759)`, `.pink` -> `Color(0xFFFF2D55)`, `.cyan` -> `Color(0xFF32ADE6)`, `.gray` -> `Color(0xFF8E8E93)`; never Compose `Color.Blue` and the like.
