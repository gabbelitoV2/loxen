## CryptoKit (CK, package com.moblin.android.platform.cryptokit)
- CryptoKit keeps its names: import `SHA256`, `SHA384`, `SHA512`, `Insecure`, `HMAC`, `HashedAuthenticationCode`, `SymmetricKey`, `SymmetricKeySize`, `AES`, `P256`, `SharedSecret`, `CryptoKitError` and `CryptoKitASN1Error` from `com.moblin.android.platform.cryptokit`. Never use `MessageDigest`, `Mac`, `Cipher`, `SecretKeySpec`, `GCMParameterSpec`, `KeyAgreement`, `KeyFactory`, `KeyPairGenerator`, `java.security.PrivateKey`/`PublicKey` or hand-written PEM, DER or nonce layouts for them in a translated file: the shim produces Apple's bytes (nonce + ciphertext + tag boxes, PKCS#8 PEM without a trailing newline, X9.63 and SubjectPublicKeyInfo keys) and reads what iOS Moblin writes.
- Hashes: `SHA256.hash(data: d)` -> `SHA256.hash(data = d)` (also `SHA384`, `SHA512`, `Insecure.SHA1`, `Insecure.MD5`) with `d: ByteArray` (`Data(s.utf8)` -> `s.utf8Data`); `Data(SHA256.hash(data: d))`, `Array(digest)` and `digest.withUnsafeBytes { Data($0) }` -> `SHA256.hash(data = d).toByteArray()`; `Data(digest.prefix(16))` -> `digest.prefix(16)` (a `ByteArray`). `var h = Insecure.MD5(); h.update(data: d); Data(h.finalize())` -> `val h = Insecure.MD5(); h.update(data = d); h.finalize().toByteArray()` (`finalize()` does not reset). Digests compare with `==`; `digest == data` -> `digest.contentEquals(data)`; `"\(digest)"` prints Apple's `SHA256 digest: <hex>`.
- HMAC takes the hash type as its first argument: `HMAC<SHA256>.authenticationCode(for: d, using: k)` -> ``HMAC.authenticationCode(SHA256, `for` = d, using = k)``; `HMAC<SHA256>.isValidAuthenticationCode(mac, authenticating: d, using: k)` -> `HMAC.isValidAuthenticationCode(SHA256, mac, authenticating = d, using = k)` (`mac` a `HashedAuthenticationCode<SHA256>` or a `ByteArray`); `var h = HMAC<SHA256>(key: k)` -> `val h = HMAC(SHA256, key = k)` with `update(data = d)` and `finalize()`; `Data(mac)` -> `mac.toByteArray()`, `Data(mac.prefix(n))` -> `mac.prefix(n)`.
- Keys: `SymmetricKey(data: d)` -> `SymmetricKey(data = d)` (a `ByteArray` or a digest), `SymmetricKey(size: .bits256)` -> `SymmetricKey(size = SymmetricKeySize.bits256)`, `key.bitCount`, `key.withUnsafeBytes { Data($0) }` -> `key.withUnsafeBytes { it }`. A stored key stays a `SymmetricKey`, never a `SecretKey` or a `ByteArray`.
- AES-GCM: `AES.GCM.seal(d, using: k)` -> `AES.GCM.seal(d, using = k)`, adding `nonce = n` and `authenticating = aad` only when Swift passes them; `AES.GCM.open(box, using: k, authenticating: aad)` -> `AES.GCM.open(box, using = k, authenticating = aad)`; `AES.GCM.SealedBox(combined: d)` -> `AES.GCM.SealedBox(combined = d)`; `AES.GCM.SealedBox(nonce: .init(data: n), ciphertext: c, tag: t)` -> `AES.GCM.SealedBox(nonce = AES.GCM.Nonce(data = n), ciphertext = c, tag = t)`. `box.combined` is `ByteArray?` as in Swift (`try? AES.GCM.seal(d, using: k).combined` -> `runCatching { AES.GCM.seal(d, using = k).combined }.getOrNull()`), `box.ciphertext` and `box.tag` are `ByteArray`, and `Data(box.nonce)` or `Data(box.nonce.makeIterator())` -> `box.nonce.toByteArray()`.
- P256: `P256.KeyAgreement.PrivateKey()`, `P256.KeyAgreement.PrivateKey(pemRepresentation: s)` -> `P256.KeyAgreement.PrivateKey(pemRepresentation = s)`; `pemRepresentation`, `derRepresentation`, `rawRepresentation`, `x963Representation` and `publicKey` are properties, never calls. `P256.KeyAgreement.PublicKey(x963Representation: d)`, `(derRepresentation: d)`, `(rawRepresentation: d)` and `(pemRepresentation: s)` keep the label as a named argument (the byte-array constructors differ only by that name; never pass their `Unit` parameters). `priv.sharedSecretFromKeyAgreement(with: pub)` -> `priv.sharedSecretFromKeyAgreement(with = pub)`; `secret.withUnsafeBytes { buffer in Data(bytes: buffer.baseAddress!, count: buffer.count) }` -> `secret.withUnsafeBytes { buffer -> buffer.copyOf() }`.
- An `extension P256.KeyAgreement.PublicKey { init(bytes: Data) throws { try self.init(derRepresentation: header + bytes) } }` -> `operator fun P256.KeyAgreement.PublicKey.Companion.invoke(bytes: ByteArray): P256.KeyAgreement.PublicKey = P256.KeyAgreement.PublicKey(derRepresentation = header + bytes)`, called as `P256.KeyAgreement.PublicKey(bytes = d)`; `func toBytes() -> Data { derRepresentation[26...] }` -> `fun P256.KeyAgreement.PublicKey.toBytes(): ByteArray = derRepresentation.copyOfRange(26, derRepresentation.size)`.
- Every throwing call above throws a Kotlin exception like Swift: `CryptoKitError` (objects `incorrectKeySize`, `incorrectParameterSize`, `authenticationFailure`, `wrapFailure`, `unwrapFailure`, `invalidParameter`, class `underlyingCoreCryptoError(error)`) or, for PEM and DER input, `CryptoKitASN1Error` (`invalidPEMDocument`, ...). Keep Swift's `do`/`catch` as `try`/`catch (error: Exception)`; `"\(error)"` -> `"$error"` prints the Swift case name; `catch CryptoKitError.authenticationFailure` -> `catch (e: CryptoKitError) { if (e == CryptoKitError.authenticationFailure) ... }`.
