## Core Image, MetalPetal, CoreGraphics and simd (E1, packages com.moblin.android.platform.coreimage, .metalpetal, .coregraphics, .simd)
- CIImage, CIContext, CIFilter (built-ins through `CIFilter.gaussianBlur()` etc.), CIColor, CIVector, CIWarpKernel, CIColorKernel -> coreimage. MTIImage, MTIContext, MTILayer, MTIMask, MTIColor, MTIColorMatrix, MTICornerRadius, MTICropRegion, MTIAlphaType, MTIBlendMode, MTLCreateSystemDefaultDevice, MTKTextureLoader.Option and every MTI*Filter -> metalpetal. Keep every Swift call, label and `?? image` fallback; these are lazy and cheap, safe per frame on the pipeline thread. Never TODO them, never replace them with Bitmap or CVPixelBuffer, never declare placeholder classes for them.
- CGRect, CGSize, CGPoint, CGAffineTransform, CGImagePropertyOrientation, CGColorSpace, CGColor, CGContext, CGMutablePath, CGImageAlphaInfo -> coregraphics (Double fields). Use them for all geometry that touches CIImage, MTIImage, MTILayer, CIFilter, Vision or VideoEffect. SwiftUI views, Path and Canvas keep Compose geometry. `CGRect.null` -> `CGRect.nullRect`; `.zero` -> `CGRect.zero`/`CGSize.zero`/`CGPoint.zero`; `CGAffineTransform(translationX:y:)`, `(scaleX:y:)`, `(rotationAngle:)` keep their labels as named arguments (Double). `size.minimum()`/`maximum()` are CGSize members. Converters: `.toCGSize()`, `.toCGPoint()`, `.toCGRect()` on android.util.Size/SizeF and Compose Size/Offset/Rect; `CGSize.toComposeSize()`, `CGPoint.toOffset()`, `CGRect.toComposeRect()`; `imageBuffer.size` of a CVPixelBuffer -> `imageBuffer.cgSize`. CoreGraphics values are immutable: `r.origin.x += 1` -> `r = r.copy(x = r.origin.x + 1)`, `r.size.width -= 2` -> `r = r.copy(width = r.size.width - 2)`, `p.x = v` -> `p = p.copy(x = v)`. `CGMutablePath` is an android.graphics.Path. `CGContext(data: &pixels, …)` -> `CGContext(data = pixels, …)` with a ByteArray; `cgImage.dataProvider?.data` -> `cgImage.dataProvider?.data` (ByteArray?), `CFDataGetLength(d)` -> `d.size`, `CFDataGetBytePtr(d)` -> `d`, `bitsPerComponent`/`bitsPerPixel` are Bitmap extensions.
- Keep the public effect signatures that other files call (Compose Size for canvasSize, videoSize and size; settings enums in TextEffect; String model path in PngTuberEffect; String vrm path in VTuberVrmEffect and java.io.File directory in VTuberLive2DEffect; java.net.URI url and java.net.InetSocketAddress proxy in BrowserEffect; android.location.Location in MapEffect; the existing AlertsEffectAlert sealed class and its case names); convert inside.
- `CIImage(cvPixelBuffer:)` and `CIImage(cvImageBuffer:)` -> `CIImage(cvPixelBuffer = b)`; `CIImage(cgImage: c)` -> `CIImage(cgImage = c)` (c is a Bitmap); `CIImage(image: u)`, `CIImage(data:options:)` -> nullable, named arguments; `[.applyOrientationProperty: true]` -> `mapOf(CIImageOption.applyOrientationProperty to true)`; `image.oriented(.right)` -> `image.oriented(CGImagePropertyOrientation.right)`; `CIImage.black`/`.white`/`.clear` and `CIImage.empty()` keep their names. Compare images with `===`/`!==`.
- A Swift `class X: CIFilter { override var outputImage }` -> `class X : CIFilter() { override val outputImage: CIImage? get() = ... }`. Built-in filter properties keep Apple's names and types (`radius: Float`, `center: CGPoint`, `extent: CGRect`, `color: CIColor`); `filter.setValue(v, forKey: kCIInputImageKey)` keeps its shape. `try? CIWarpKernel(functionName:fromMetalLibraryData:)` -> `runCatching { CIWarpKernel(functionName = n, fromMetalLibraryData = d) }.getOrNull()`; `Bundle.main.url(forResource: "default", withExtension: "metallib")` -> `Bundle.url("default", "metallib")` and `Data(contentsOf: url)` -> `java.io.File(url).readBytes()`; `kernel.apply(extent:roiCallback:image:arguments:)` -> `kernel.apply(extent = e, roiCallback = { _, rect -> ... }, image = i, arguments = listOf(...))`.
- `MTILayer(content:...)` keeps its labels and MetalPetal's defaults (`rotation` and `opacity` are Float); layer content `.white`/`.black` -> `MTIImage.white`/`MTIImage.black`; FlipOptions `[]` -> `MTILayer.FlipOptions.donotFlip`, `[.flipHorizontally]` -> `MTILayer.FlipOptions.flipHorizontally`; `.fractional(r)` -> `MTICropRegion.fractional(r)`; `MTIColor(red:green:blue:alpha:)` takes Float; `MTIImage(cgImage: c, options: [.SRGB: false], isOpaque: true)` -> `MTIImage(cgImage = c, options = mapOf(MTKTextureLoader.Option.SRGB to false), isOpaque = true)`; `image.size`/`image.extent` are CGSize/CGRect. `try metalPetalContext?.render(image, to: buffer)` -> the same call inside try/catch. MTIImage `==`/`!=` -> `===`/`!==`.
- simd: `SIMD4<Float>(a, b, c, d)` -> `SIMD4(a, b, c, d)`; `simd_float4x4(columns: (a, b, c, d))` -> `simd_float4x4(columns = listOf(a, b, c, d))`; `float3x3(rows: [a, b, c])` -> `float3x3(rows = listOf(a, b, c))`; the unlabeled `simd_float4x4(a, b, c, d)` and `.init(a, b, c, d)` in a matrix position -> `simd_float4x4(a, b, c, d)` (columns); `m[i]` is column i; `distance`, `length`, `normalize`, `dot` and vector `+ - * /` are platform.simd functions and operators; `simd_make_float2(x, y)` and `.init(x, y)` for simd_float2 -> `SIMD2(x, y)`.
- `CIContext()` -> `CIContext()`; `context.render(image, to: buffer)` and `render(image, to:bounds:colorSpace:)` keep their shape; `context.createCGImage(image, from: r)` returns Bitmap?.
- Pipeline boundary: `VideoUnit.canvasSize` is android.util.Size (use `.toCGSize()`); `VideoEffectInfo.presentationTimeStamp` is Long microseconds (`.seconds` -> `/ 1_000_000.0`); `createBlackImage(width:height:)` returns CIImage; Moblin's `MetalPetalWidgetShape` is a data class whose `inout` use mutates the object, and a struct parameter kept by the callee is `.copy()`.
