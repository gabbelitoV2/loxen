## System volume (VOL, package com.moblin.android.platform.mediaplayer)
- `MPVolumeView(frame: .zero)` -> `MPVolumeView(frame = CGRect.zero)` (CGRect from com.moblin.android.platform.coregraphics); Model's `let volumeView` keeps that type, never `Any?`. Creating one makes the platform post `"SystemVolumeDidChange"` (`SystemVolume.didChangeNotification`) when the Android media volume changes.
- `volumeView.subviews.first(where: { $0 is UISlider }) as? UISlider` -> `volumeView.subviews.firstOrNull { it is UISlider } as? UISlider` (com.moblin.android.platform.uikit.UISlider). `volumeSlider.value = volume` sets the media (STREAM_MUSIC) volume, 0...1 over the stream's range, without showing the volume panel; reading `value` returns it.
- `addObserver(Notification.Name("SystemVolumeDidChange"), #selector(handleSystemVolumeDidChange))` -> `NotificationCenter.default.addObserver(this, SystemVolume.didChangeNotification, null) { handleSystemVolumeDidChange(it) }`, never Model's `addObserver(name, selector)`. userInfo: `"Volume"` (Float 0...1), `"Reason"` (always `"ExplicitVolumeChange"`) and `"SequenceNumber"` (Int, shared by duplicates of one change). A volume key press in the app at 0 or 1 is posted too, with the same volume and a new `"SequenceNumber"`, like iOS.
- `latestSetVolumeTime` is a `ContinuousClock.Instant` (com.moblin.android.platform.core): `= .now` -> `= ContinuousClock.now`; `latestSetVolumeTime.duration(to: .now) > .seconds(1)` -> `latestSetVolumeTime.duration(to = ContinuousClock.now).toDouble(DurationUnit.SECONDS) > 1.0`, never java.time.
