## Speech recognition and translation (STT, packages com.moblin.android.platform.speech and com.moblin.android.platform.translation)
- `SFSpeechRecognizer()` -> `SFSpeechRecognizer()` (device locale, never null, no Context: `speechRecognizer?.x` -> `speechRecognizer.x`). `SpeechToText()` takes no Context either. `speechRecognizer.delegate = self` -> `speechRecognizer.delegate = this` with the class implementing `SFSpeechRecognizerDelegate` (`fun speechRecognizer(speechRecognizer: SFSpeechRecognizer, availabilityDidChange: Boolean)`); never `android.speech.SpeechRecognizer` or `RecognitionListener`.
- `SFSpeechRecognizer.requestAuthorization { authStatus in DispatchQueue.main.async { switch authStatus { ... } } }` -> `SFSpeechRecognizer.requestAuthorization { authStatus -> mainScope.launch { when (authStatus) { SFSpeechRecognizerAuthorizationStatus.authorized -> ...; .denied, .restricted, .notDetermined -> ... } } }`; the enum is closed, so `@unknown default` is dropped.
- `SFSpeechAudioBufferRecognitionRequest()`, `shouldReportPartialResults`, `addsPunctuation`, `appendAudioSampleBuffer(sampleBuffer)` (a `MediaSample`, any raw PCM format) and `endAudio()` keep their shape. `speechRecognizer.recognitionTask(with: request, resultHandler: { result, error in })` -> `speechRecognizer.recognitionTask(with = request) { result, error -> }`, which returns an `SFSpeechRecognitionTask` (with `cancel()` and `finish()`) for a `SFSpeechRecognitionTask?` property; `return` inside the handler -> `return@recognitionTask`. `result.bestTranscription.formattedString` and `result.isFinal` keep their names. The handler runs on the main thread.
- `ContinuousClock.Instant` values in SpeechToText stay `Long` nanoseconds of `SystemClock.elapsedRealtimeNanos()`: `latestResultTime = .now` -> `latestResultTime = SystemClock.elapsedRealtimeNanos()`, `tick(now:)` takes that `Long` and `.seconds(2)` -> `2_000_000_000L`.
- `Locale.Language` is `java.util.Locale`: `Locale.current.language` -> `Locale.getDefault()`, `Locale.Language(identifier: x)` and `.init(identifier: x)` -> `localeLanguage(identifier = x)`, `language.minimalIdentifier` -> `language.minimalIdentifier` (extension in com.moblin.android.platform.translation), `language.name()` -> `language.name()` (com.moblin.android.various.utils).
- `TranslationSession(installedSource: s, target: t)` -> `TranslationSession(installedSource = s, target = t)`; `try await session.translate(text)` -> `session.translate(text)` (suspend) whose `response.targetText` is the translation. `catch let error as TranslationError` -> `catch (error: TranslationError)` with `error.failureReason` (String?) and `error.localizedDescription`; a plain `catch` -> `catch (error: Exception)`. Never `TODO()` for Translation.
- `LanguageAvailability()`: `await availability.supportedLanguages` -> `availability.supportedLanguages()` (suspend, `List<Locale>`), `await availability.status(from: a, to: b)` -> `availability.status(from = a, to = b)` returning `LanguageAvailability.Status.installed`, `.supported` or `.unsupported`. A SwiftUI `.task { }` that calls them -> `LaunchedEffect(Unit) { }` in the same place. `#available(iOS 26, *)` checks around Translation are dropped.
