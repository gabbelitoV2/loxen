## Text widgets (E3)
- TextEffectFormatter is kept hand-maintained Kotlin: call `TextEffectFormatter(formatParts = …, timersEndTime = …, stopwatches = …, checkboxes = …, ratings = …, lapTimes = …)` and `formatter.format(variables, now)` with `now: ContinuousClock.Instant`, exactly as declared; never re-declare its types (`TextEffectLine`, `TextEffectPart`, `TextEffectPartData`) or those of the kept TextFormatStringLoader (`TextFormatPart`, `loadTextFormat(format = …)`).
- Timer end times are `ContinuousClock.Instant` (import com.moblin.android.platform.core.ContinuousClock): the elements of `TextEffect`'s `timersEndTime`, `setTimersEndTime(endTimes:)` and `setEndTime(index:endTime:)`. `Variables(timestamp: .now, …)` -> `timestamp = ContinuousClock.now.nanoseconds`; `format(…, now: .now)` -> `now = ContinuousClock.now`.
- TextEffect's init and setters keep the types its callers pass: `fontSize: CGFloat` -> Float, `fontDesign: Font.Design` -> com.moblin.android.view.utils.FontDesign, `fontWeight: Font.Weight` -> androidx.compose.ui.text.font.FontWeight, `horizontalAlignment: HorizontalAlignment` -> SettingsHorizontalAlignment.
- DrawOnStreamEffect keeps Swift's CoreGraphics types: `updateOverlay(videoSize: CGSize, size: CGSize, lines: List<DrawOnStreamLine>, mirror: Boolean)` and `drawOnStreamCreatePath(points: List<CGPoint>): androidx.compose.ui.graphics.Path`; DrawOnStreamLine.points are Compose Offsets (`point.toCGPoint()`).
- `DispatchQueue.global().async { … }` -> `CoroutineScope(Dispatchers.Default).launch { … }`.
- In `renderer.objectWillChange.sink { [weak self] in … }` read every member through the weak reference (`weakSelf.get()?.let { self -> self.setOverlay(image = self.renderer?.cgImage) }`); a bare member name in the lambda captures `this` and keeps the effect alive.
- SwiftUI named colours are the iOS system colours: `.yellow` -> `Color(0xFFFFCC00)`, never Compose `Color.Yellow`.
- Tests: a `WeatherCondition` case is the String that TextEffectFormatter matches, in UpperCamelCase (`.clear` -> `"Clear"`, `.rain` -> `"Rain"`); keep every U+00A0 no-break space of an expected string, written `\u00A0` (`"1\u00A0700 m"`).
