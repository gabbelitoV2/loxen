## Scenes, windows and the presenting view controller (WIN, packages com.moblin.android.platform.uikit and com.moblin.android.platform.audiotoolbox)
- `UIApplication.shared.connectedScenes` -> `UIApplication.shared.connectedScenes` (`Set<UIScene>`: the scene of the resumed Activity, empty before one resumes); `.first` -> `.firstOrNull()`, `.first(where: { $0 is UIWindowScene })` and `as? UIWindowScene` keep their shape. `windowScene.windows.first` -> `windowScene.windows.firstOrNull()`, `window.rootViewController` (`UIViewController?`, which holds the Activity as `.activity`), `window.screen.scale` and `UIScreen.main.scale` (`Float`); after an optional every member access stays safe: `getWindow()?.screen.scale ?? UIScreen.main.scale` -> `getWindow()?.screen?.scale ?: UIScreen.main.scale`. Never write `null` or TODO() for them.
- `windowScene.interfaceOrientation` -> an `Int` in `UIInterfaceOrientation` (`unknown`, `portrait`, `portraitUpsideDown`, `landscapeLeft`, `landscapeRight`); `case .landscapeLeft:` -> `UIInterfaceOrientation.landscapeLeft ->`.
- `UIDevice.current.userInterfaceIdiom == .phone` (`.pad`) -> `com.moblin.android.platform.uikit.UIDevice.current.userInterfaceIdiom == UIUserInterfaceIdiom.phone` (`.pad`), importing the extension property `com.moblin.android.platform.uikit.userInterfaceIdiom`. `ProcessInfo().isMacCatalystApp` -> `false`.
- `AudioServicesPlaySystemSound(kSystemSoundID_Vibrate)` -> the same call, both names imported from `com.moblin.android.platform.audiotoolbox`.
- UiUtils.swift keeps the Kotlin shapes its callers use: `extension UIDevice { static func vibrate() }` -> `object UIDevice { fun vibrate() }`, so the UIKit `UIDevice` is written fully qualified in that file; `getOrientation() -> UIDeviceOrientation` -> `fun getOrientation(): DeviceOrientation {` after `enum class DeviceOrientation { UNKNOWN, PORTRAIT, PORTRAIT_UPSIDE_DOWN, LANDSCAPE_LEFT, LANDSCAPE_RIGHT, FACE_UP, FACE_DOWN }`, where a hook adds the `UIDevice.current.orientation` check, so the body starts at the interface orientation; `makeOffsets(_:_:) -> IndexSet?` -> `fun <ID, T : Identifiable<ID>> makeOffsets(items: List<T>, id: ID): Int?` after `interface Identifiable<ID> { val id: ID }`; `UIImage.resize(height:)` -> `fun Bitmap.resize(height: Float): Bitmap`, whose one-pixel-per-point renderer and `draw(in:)` are `Bitmap.createScaledBitmap(this, (width * (height / this.height)).toInt(), height.toInt(), true)`.
