## Camera capture shims (T3, packages com.moblin.android.platform.avfoundation and com.moblin.android.platform.uikit)

- Every `AVCapture*` type used by the capture code has a same-named class in `com.moblin.android.platform.avfoundation`: `AVCaptureSession`, `AVCaptureMultiCamSession`, `AVCaptureInput`, `AVCaptureDeviceInput`, `AVCaptureInputPort`, `AVCaptureOutput`, `AVCaptureVideoDataOutput`, `AVCaptureVideoDataOutputSampleBufferDelegate`, `AVCaptureConnection`, `AVCapturePhotoOutput`, `AVCapturePhotoSettings`, `AVCapturePhoto`, `AVCapturePhotoCaptureDelegate`, `AVCaptureSessionControlsDelegate`, `AVFrameRateRange`, `AVError` and `AVCaptureDevice`. Never declare stand-ins for them, and never call Camera2 or CameraX from generated code. The audio members (`AVCaptureAudioDataOutput`, `AVAudioSession`) are in the same package (T5).
- `AVCaptureDevice(uniqueID: id)` -> `AVCaptureDevice.withUniqueID(id)`, which returns `AVCaptureDevice?` and one cached instance per id, so devices compare with `==`/`===` and work as map keys.
- `AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: .back)` -> `AVCaptureDevice.default(AVCaptureDevice.DeviceType.builtInWideAngleCamera, AVMediaType.video, AVCaptureDevice.Position.back)`. `AVCaptureDevice.default(for: .audio)` -> `AVCaptureDevice.default(AVMediaType.audio)`.
- `AVCaptureDevice.DiscoverySession(deviceTypes: [...], mediaType: .video, position: .back).devices` -> `AVCaptureDevice.DiscoverySession(deviceTypes = listOf(...), mediaType = AVMediaType.video, position = AVCaptureDevice.Position.back).devices`.
- Enum cases keep their Swift spelling: `AVCaptureDevice.Position.back/front/unspecified`, `AVCaptureDevice.DeviceType.builtInTripleCamera/.../external/microphone`, `AVCaptureDevice.TorchMode.off/on/auto`, `AVCaptureDevice.ExposureMode`, `FocusMode`, `WhiteBalanceMode`, `AVMediaType.video/audio`, `AVCaptureAspectRatio.ratio9x16`, `AVCapturePhotoOutput.QualityPrioritization.balanced` (an `Int`). `Position.rawValue` is Apple's; `Position.ordinal` equals `CameraSelector.LENS_FACING_FRONT/BACK`.
- `AVCaptureVideoOrientation` values are `Int` constants: `AVCaptureVideoOrientation.portrait/portraitUpsideDown/landscapeRight/landscapeLeft` (Apple raw values 1-4). Declare `videoOrientation: Int` and never use `Surface.ROTATION_*` for it.
- `AVCaptureColorSpace` values are `Int` constants: `AVCaptureColorSpace.sRGB`, `.HLG_BT2020`, `.P3_D65`, `.appleLog`. String interpolation of a color space (`"\(colorSpace)"`) -> `AVCaptureColorSpace.description(colorSpace)` from `com.moblin.android.media.haishinkit.extension`.
- `device.activeFormat.formatDescription.dimensions.width/height` and `.mediaSubType.rawValue` keep their Swift shape. `format.videoSupportedFrameRateRanges`, `supportedColorSpaces`, `isVideoBinned`, `isAutoVideoFrameRateSupported`, `supportedDynamicAspectRatios`, `supportedMaxPhotoDimensions` (`List<android.util.Size>`), `videoMaxZoomFactor`, `minISO`, `maxISO`, `minExposureDuration` and `maxExposureDuration` exist. `CMTime` durations are `Long` microseconds, and `.invalid` is `kCMTimeInvalidUs`.
- `try device.lockForConfiguration()` -> `device.lockForConfiguration()` inside the translated `try`; always keep `unlockForConfiguration()`, which applies the batched changes. `device.ramp(toVideoZoomFactor: x, withRate: r)` -> `device.ramp(toVideoZoomFactor = x, withRate = r)`. `try device.setTorchModeOn(level: l)` -> `device.setTorchModeOn(level = l)`.
- `try AVCaptureDeviceInput(device: d)` -> `AVCaptureDeviceInput(device = d)`, which throws `AVError`. `AVCaptureConnection(inputPorts: [port], output: o)` -> `AVCaptureConnection(inputPorts = listOf(port), output = o)`; `AVCaptureConnection(inputPort: port, videoPreviewLayer: layer)` keeps its labels.
- `output.setSampleBufferDelegate(self, queue: processorPipelineQueue)` -> `output.setSampleBufferDelegate(this, processorPipelineQueue)`; the delegate method is `captureOutput(output, didOutput: MediaSample, from: AVCaptureConnection)`.
- `output.videoSettings = [kCVPixelBufferPixelFormatTypeKey as String: x]` -> `output.videoSettings = mapOf(kCVPixelBufferPixelFormatTypeKey to x)`.
- `photoOutput.capturePhoto(with: settings, delegate: self)` -> `photoOutput.capturePhoto(settings = settings, delegate = this)`; the delegate method is `photoOutput(output, didFinishProcessingPhoto: AVCapturePhoto, error: Throwable?)`. `PHPhotoLibrary.shared().performChanges { ... } completionHandler: { _, error in ... }` -> `PHPhotoLibrary.shared().performChanges({ ... }) { _, error -> ... }`, and `PHAssetCreationRequest.forAsset().addResource(with: .photo, data: d, options: nil)` -> `addResource(with = PHAssetResourceType.photo, data = d, options = null)`.
- `.AVCaptureSessionRuntimeError`, `.AVCaptureSessionWasInterrupted`, `.AVCaptureSessionInterruptionEnded` and `AVCaptureSessionErrorKey` are `String` constants. `notification.userInfo?[AVCaptureSessionErrorKey] as? AVError` -> `notification.userInfo[AVCaptureSessionErrorKey] as? AVError`; `error._nsError.localizedFailureReason` -> `error.localizedFailureReason`.
- `AVCaptureVideoPreviewLayer` is a typealias of the haishinkit `PreviewView`. `previewLayer.session` and `previewLayer.setSessionWithNoConnection(session)` are extensions from `com.moblin.android.platform.avfoundation`; import them.
- `session.synchronizationClock` is a `CMClock?`; `clock.convertTime(pts, to: CMClockGetHostTimeClock())` -> `clock.convertTime(pts)`, the identity, because every timestamp is already host microseconds.
- The iOS 18 camera controls (`AVCaptureSystemZoomSlider`, `AVCaptureSystemExposureBiasSlider`, `session.controls`, `setControlsDelegate`) have no Android counterpart: `session.supportsControls` is `false`, and `addCameraControls`/`removeCameraControls` keep empty bodies.
- Model zoom (`Media.swift` `setCameraZoomLevel`/`stopCameraZoomLevel`) -> `com.moblin.android.platform.avfoundation.setCameraZoomLevel(device, level, rate)` and `stopCameraZoomLevel(device)`.
- `UIDevice.current.orientation` -> `com.moblin.android.platform.uikit.UIDevice.current.orientation`, an `Int` in `UIDeviceOrientation` (`unknown`, `portrait`, `portraitUpsideDown`, `landscapeLeft`, `landscapeRight`, `faceUp`, `faceDown`). `UIDevice.orientationDidChangeNotification` is posted through `NotificationCenter`; `com.moblin.android.various.utils.UIDevice` is unrelated (vibration only).
- `CMAcceleration` stays the data class in `com.moblin.android.various.utils`.
