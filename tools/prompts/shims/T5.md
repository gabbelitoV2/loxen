## Audio session, audio capture and audio converter shims (T5, packages com.moblin.android.platform.avfoundation and com.moblin.android.platform.audio)

- `AVAudioSession.sharedInstance()` -> `AVAudioSession.sharedInstance()` from `com.moblin.android.platform.avfoundation`. Keep the members: `availableInputs` (`List<AVAudioSessionPortDescription>?`), `preferredInput`, `setPreferredInput(port)`, `currentRoute.inputs`/`currentRoute.outputs`, `inputDataSource`, `setInputDataSource(dataSource)`, `isInputGainSettable`, `inputGain`, `setInputGain(gain)`, `sampleRate`, `preferredSampleRate`, `setPreferredSampleRate(48000.0)`, `setPrefersNoInterruptionsFromSystemAlerts(value)`, `setAllowHapticsAndSystemSoundsDuringRecording(value)` and `setActive(active)`. None of them throw, so `try`/`try?` around them may stay as `try`/`runCatching`.
- `session.setCategory(.playAndRecord, mode: .x, options: [.a, .b])` -> `session.setCategory(AVAudioSession.Category.playAndRecord, mode = AVAudioSession.Mode.x, options = AVAudioSession.CategoryOptions.a or AVAudioSession.CategoryOptions.b)`. Categories and modes are `String` constants, options are `Int` flags.
- `AVAudioSession.Port.builtInMic` (and `headsetMic`, `usbAudio`, `bluetoothHFP`, `bluetoothLE`, `lineIn`, ...), `AVAudioSession.Orientation.bottom/front/back/top`, `AVAudioSession.PolarPattern.stereo` and `AVAudioSession.RouteChangeReason.*` are constants nested in `AVAudioSession`; `portType`, `orientation` and polar patterns are `String`s, so compare with `==`.
- `AVAudioSessionPortDescription` has `uid`, `portName`, `portType`, `dataSources`, `preferredDataSource`, `selectedDataSource`. `AVAudioSessionDataSourceDescription` has `dataSourceID` (an `Int`, so `dataSourceID.intValue` -> `dataSourceID` and `mic.dataSourceId as? NSNumber` -> `mic.dataSourceId`), `dataSourceName`, `orientation`, `supportedPolarPatterns`, `preferredPolarPattern` and `setPreferredPolarPattern(pattern)`. `setPreferredPolarPattern(.none)` means Swift `nil` -> `setPreferredPolarPattern(null)`.
- `AVAudioSession.routeChangeNotification` is the `String` `"AVAudioSession.routeChangeNotification"`; it is posted through `NotificationCenter.default` from `com.moblin.android.platform.core` with `userInfo[AVAudioSessionRouteChangeReasonKey]`. A handler `@objc func f(notification: Notification)` -> `fun Model.f(notification: Notification)` with `com.moblin.android.platform.core.Notification`, never `android.content.Intent`.
- `session.observe(\.inputGain) { session, _ in ... }` -> `session.observeInputGain { session -> ... }`, which returns the observation token (`Any`).
- `AVCaptureDevice.default(for: .audio)` -> `AVCaptureDevice.default(AVMediaType.audio)`: one generic microphone device that follows `setPreferredInput`/`setInputDataSource`/`setPreferredPolarPattern` when the capture session commits or starts, as on iOS.
- `AVCaptureAudioDataOutput()`, `output.setSampleBufferDelegate(self, queue: processorPipelineQueue)` -> `output.setSampleBufferDelegate(this, processorPipelineQueue)`. `AVCaptureAudioDataOutputSampleBufferDelegate.captureOutput(_:didOutput:from:)` -> `override fun captureOutput(output: AVCaptureOutput, didOutput: MediaSample, from: AVCaptureConnection?)`. Audio devices and outputs are added to an `AVCaptureSession` exactly like video ones (`beginConfiguration`, `canAddInput`, `addInput`, `canAddOutput`, `addOutput`, `commitConfiguration`, `startRunning`, `stopRunning`); the session drives `AudioCaptureEngine`, which generated code never calls.
- Captured audio is a `MediaSample` of interleaved little-endian 16-bit PCM, 1024 frames at 48 kHz, host-clock microseconds in `presentationTimeUs`, and one shared raw `MediaFormat` per capture configuration. `session.synchronizationClock` is a `CMClock`: `audioClock.convertTime(pts, to: CMClockGetHostTimeClock())` -> `audioClock.convertTime(pts)` (identity).
- `AVAudioFormat` and `AudioStreamBasicDescription` -> `android.media.MediaFormat`. Comparing two of them (`a != b`, `guard x != old`) -> `a.isSameAudioFormat(b)` from `com.moblin.android.platform.audio`, never `==`. `CMSampleBuffer.numSamples` -> `sampleBuffer.numSamples`. A raw PCM format is `makePcmFormat(sampleRate, channels)` from `com.moblin.android.platform.audio`.
- `AVAudioConverter(from: a, to: b)` -> `AVAudioConverter.create(from = a, to = b)` (nullable). Keep `channelMap` (a `List<Int>`, `-1` is silence), `bitRate`, `applicableEncodeBitRates` (`List<Int>?`), `inputFormat` and `outputFormat`. `converter.convert(to: out, error: &error) { _, status in status.pointee = .haveData; return input }` -> `val error = converter.convert(to = out) { input.data }`, which returns an error `String?`; `try converter.convert(to: pcmOut, from: pcmIn)` -> `val error = converter.convert(to = pcmOut, from = pcmIn)`. When a converter is replaced or dropped, call `converter.release()` first.
- `AVAudioCompressedBuffer(format:packetCapacity:maximumPacketSize:)` -> `AVAudioCompressedBuffer(format = f, packetCapacity = 1, maximumPacketSize = n)` and `AVAudioPCMBuffer(pcmFormat:frameCapacity:)` -> `AVAudioPCMBuffer(pcmFormat = f, frameCapacity = n)` (nullable); both are `MediaSample`s, and the converter writes the result into `buffer.data`. One compressed buffer holds exactly one raw AAC access unit or Opus packet.
- `MPEG4ObjectID.AAC_LC` in an AAC format -> `format.setInteger(MediaFormat.KEY_AAC_PROFILE, MediaCodecInfo.CodecProfileLevel.AACObjectLC)`. An Opus format is only valid when `isOpusSampleRateSupported(rate)` and `hasAudioEncoder(format)` (both in `com.moblin.android.platform.audio`); otherwise the Swift failable initializer returns `null`.
