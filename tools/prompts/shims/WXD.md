## WeatherKit (WXD, package com.moblin.android.platform.weatherkit)
- `WeatherService`, `Weather`, `CurrentWeather` and `Wind` come from the shim; never `Any?`, `Unit` or TODO() in their place. `let weatherService = WeatherService()` -> `val weatherService = WeatherService()`, `private var weather: Weather?` -> `private var weather: Weather? = null`, `getLatestWeather() -> Weather?` -> `fun getLatestWeather(): Weather?`.
- `weather = try await weatherService.weather(for: location)` -> ``weather = weatherService.weather(`for` = location)``, a suspend function taking the `android.location.Location`. It throws when no weather could be fetched, so keep the Swift `do`/`catch` around it. `try await sleep(seconds: delay)` -> `sleepSeconds(seconds = delay)` (import com.moblin.android.common.various.sleepSeconds, `delay` an `Int`).
- `weather.currentWeather` has `symbolName` (`String`, an SF Symbol name), `condition` (`String`, the `WeatherCondition` case name with a capital first letter, for example `"MostlyClear"`), `temperature` and `apparentTemperature` (`Double` in °C), `wind` (`Wind`: `speed`, a `Double` in m/s, and `gust`, a `Double?` in m/s) and `isDaylight`.
- `WeatherCondition` -> `String`, `Measurement<UnitTemperature>` -> `Double` in °C, `Measurement<UnitSpeed>` -> `Double` in m/s, so `Variables` declares `condition: String?`, `temperature: Double?`, `feelsLikeTemperature: Double?`, `windSpeed: Double?` and `windGust: Double?`. With `val weather = weatherManager.getLatestWeather()?.currentWeather`: `weather?.temperature` and `.converted(to: .celsius).value` -> `weather?.temperature`, `weather?.wind.speed` and `.converted(to: .metersPerSecond).value` -> `weather?.wind?.speed`, `weather?.wind.gust?.converted(to: .metersPerSecond).value` -> `weather?.wind?.gust`.
- `Variables.timestamp` is a `Long` of ContinuousClock nanoseconds: `let timestamp: ContinuousClock.Instant` -> `val timestamp: Long`.
- `geographyManager.getLatestPlacemark()` is an `android.location.Address?`: `placemark?.country` -> `placemark?.countryName`, `isoCountryCode` -> `countryCode`, `administrativeArea` -> `adminArea`, `subAdministrativeArea` -> `subAdminArea`; `locality` and `subLocality` keep their names.
