## SceneKit, VRM and Live2D (E11, packages com.moblin.android.platform.scenekit and com.moblin.android.platform.live2d)
- SCNRenderer, SCNScene, SCNNode, SCNCamera, SCNVector3, SCNVector4, SCNAntialiasingMode, VRMSceneLoader, VRMScene, VRMNode, Humanoid, BlendShapeKey and BlendShapePreset -> platform.scenekit with Swift's names; never TODO them. `SCNRenderer(device: nil)` -> `SCNRenderer(device = null)`; `renderer.snapshot(atTime: t, with: s, antialiasingMode: .none)` -> `renderer.snapshot(atTime = t, with = s, antialiasingMode = SCNAntialiasingMode.none)`, which returns a Bitmap (not null). `try VRMSceneLoader(withURL: u).loadScene()` -> `VRMSceneLoader(withURL = path).loadScene()` inside one try/catch (both throw). `SCNVector3(a, b, c)` and `SCNVector4(a, b, c, d)` take Float, Double or mixed numbers. `node.humanoid.node(for: .neck)?.eulerAngles = v` -> ``node.humanoid.node(`for` = Humanoid.Bones.neck)?.eulerAngles = v``; `node.setBlendShape(value: v, for: .preset(.a))` -> ``node.setBlendShape(value = v, `for` = BlendShapeKey.preset(BlendShapePreset.a))``; `node.update(at: t)` -> `node.update(at = t)`. `SCNNode.position`, `rotation`, `eulerAngles`, `orientation` and `scale` are properties with SceneKit's semantics; assign a new vector, never mutate a component.
- AyagamiModel, AyagamiCanvas, AyagamiArtMeshInfo, AyagamiArtMeshState, AyagamiBlendMode and Live2DRenderer -> platform.live2d. `try AyagamiModel(model3Url: u)` -> `AyagamiModel(model3Url = file)` (java.io.File; throws AyagamiError) inside try/catch; `model.canvas.dimensions` is a SIMD2 (Float `x` and `y`); `model.setParameter("Id", v)` takes a Float; `model.update(deltaTime = dt)`; `model.drawOrder()` is a `List<Int>`; `model.artMeshInfo(uid)` and `model.artMeshState(uid)` take an Int and return null like Swift. `guard let r = Live2DRenderer(model: m)` -> `val r = Live2DRenderer(model = m) ?: return null` (it returns Live2DRenderer?); `renderer.render(model = m, into = pixelBuffer)`. Never translate Metal code or shader strings.
- VTuberVrmEffect keeps `vrm: String` (a path) and VTuberLive2DEffect keeps `directory: java.io.File`; PngTuberEffect's first parameter is a String path. `enum Dewarp360EffectSettings` -> a sealed class with `data class Direct(val pan: Float = 0f, val tilt: Float = 0f, val fieldOfView: Float = (PI / 2).toFloat())` and `data class Animate(val speed: Float = 1f, val pan: Float = 0f, val tilt: Float = 0f, val fieldOfView: Float = (PI / 2).toFloat())`, both subclasses of it.
