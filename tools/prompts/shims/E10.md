## Replay (E10)
- ReplayBufferFile, ReplayFrameExtractor and ReplayBuffer are kept Kotlin (com.moblin.android.various, declared `internal`): call them exactly as declared; `ReplayBufferFile(url: video.url(), …)` -> `ReplayBufferFile(url = video.url().path, duration = …, remove = …)`, and `ReplayBufferFile.url` is a String path, never a URL or File. A declaration that takes a ReplayBufferFile is `internal` too (`class ReplayEffect internal constructor(...)`, `class ReplayEffectReplayReader internal constructor(...)`).
- `CIFilter.dissolveTransition()` -> `CIFilter.dissolveTransition()` (a CITransitionFilter, com.moblin.android.platform.coreimage) with `inputImage`, `targetImage` and `time` (Float); its `outputImage` is nullable. `CMVideoDimensions` is android.util.Size (Int width and height); `CMTime(seconds: s)` -> `(s * 1_000_000.0).toLong()` microseconds; `asset.duration()` is the AVAsset member (Double seconds), never the MediaMetadataRetriever extension in Utils.kt.
- Delegates: Model passes an adapter object (`delegate = ModelReplayEffectDelegate(this)`) that nothing else references, so a Swift `weak let delegate`/`weak var delegate` -> a plain strong property (`private val delegate: ReplayEffectDelegate?`, called as `delegate?.replayEffectStatus(timeLeft = t)`); never `WeakReference(delegate)`, which is collected at the next GC.
- `switch replay.transitionType { case .none: … case .fade: … case .stingers: … }` -> `when (replay.transitionType) { SettingsStreamReplayTransitionType.none -> …; SettingsStreamReplayTransitionType.fade -> …; SettingsStreamReplayTransitionType.stingers -> … }`; never switch on `toString()`, which is the localized display name. `scene.videoSource.cameraPosition == .mediaPlayer` -> `scene.videoSource.cameraPosition == SettingsSceneCameraPosition.mediaPlayer` (an enum; SettingsCameraId is a different type, so an `is SettingsCameraId.MediaPlayer` check is always false).
- MediaPlayer's `deinit { stopOutputTimer() }` -> `override fun close()` (AutoCloseable), and Model closes every player it drops: `mediaPlayers[settings.id] = mediaPlayer` -> `mediaPlayers.put(settings.id, mediaPlayer)?.close()`, `mediaPlayers.removeValue(forKey: playerId)` -> `mediaPlayers.remove(playerId)?.close()`. `outputTimer.startPeriodic(interval: 0.3, initial: 0) { [weak self] in self?.handleOutputTimer() }` -> `val (weakSelf, timer) = java.lang.ref.WeakReference(this) to outputTimer`, then `outputTimer.startPeriodic(interval = 0.3, initial = 0.0) { weakSelf.get()?.handleOutputTimer() ?: timer.stop() }`, so the timer never roots the player.
