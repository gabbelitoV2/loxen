## App shortcuts, app icons, sharing, the Files app, settings files and background location (LSF, packages com.moblin.android.platform.appintents, com.moblin.android.platform.uikit, com.moblin.android.platform.swiftui and com.moblin.android.platform.corelocation)
- AppIntents come from `com.moblin.android.platform.appintents`: `struct X: AppIntent` -> `class X : AppIntent` without constructor parameters (`MuteIntent()` stays), its `static let title: LocalizedStringResource = "T"`, `static let description: IntentDescription? = IntentDescription("D")` and `static let openAppWhenRun: Bool` -> vals of the same types in the companion object, `@MainActor func perform() async throws -> some IntentResult` -> `override suspend fun perform(): IntentResult`, `return .result()` -> `return IntentResult.result()`, and `@Dependency private var model: Model` -> `private val model: Model by Dependency<Model>()`. The intent runs when its Android launcher shortcut is used: port every statement of perform(), never TODO() or Unit.
- `final class MoblinShortcuts: AppShortcutsProvider` -> `object MoblinShortcuts : AppShortcutsProvider` with `override val shortcutTileColor = ShortcutTileColor.navy` and `override val appShortcuts: List<AppShortcut> = listOf(AppShortcut(intent = MuteIntent(), phrases = listOf("${AppShortcutPhraseToken.applicationName}, mute"), shortTitle = "Mute", systemImageName = "microphone.slash"), ...)`; `nonisolated(unsafe)` is dropped. MoblinShortcuts has no model and no Dependency: every intent is constructed without arguments and resolves its own model. Never declare AppShortcut, ShortcutTileColor or updateAppShortcutParameters() in the file: `MoblinShortcuts.updateAppShortcutParameters()` comes from the interface.
- `AppDependencyManager.shared.add(dependency: self)` -> `AppDependencyManager.shared.add(dependency = this)`.
- `UIApplication.shared.setAlternateIconName(name) { error in ... }` -> `UIApplication.shared.setAlternateIconName(name) { error -> ... }` (`name: String?`, null is the primary AppIcon, `error: Throwable?`), importing `com.moblin.android.platform.uikit.UIApplication` and `com.moblin.android.platform.uikit.setAlternateIconName`. It switches the Android launcher icon.
- `UIApplication.shared.canOpenURL(url)`, `UIApplication.shared.open(url)` and `open(url) { success in ... }` -> the same calls (`{ success -> ... }`) with url a String or a java.net.URI, importing `com.moblin.android.platform.uikit.UIApplication`, `com.moblin.android.platform.uikit.canOpenURL` and `com.moblin.android.platform.uikit.open`. `shareddocuments://<path>` opens that directory in the Android Files app. `URL(string: "shareddocuments://\(path.path())")` -> the String `"shareddocuments://${path.path}"`, never null. `UIPasteboard.general.string = s` -> `AppDelegate.context.getSystemService(ClipboardManager::class.java)?.setPrimaryClip(ClipData.newPlainText(null, s))`.
- `ShareLink(item: x) { label }` -> `ShareLink(item = x) { label }`, imported as `com.moblin.android.platform.swiftui.ShareLink`: a plain accent button that opens the Android share sheet with x (a File, a file path String and a file java.net.URI are shared as the file, any other String as text). In its label, `Image(systemName: "s").font(.system(size: n))` -> `SystemImage(name = "s", fontSize = n.sp, tint = LocalTint.current)`. Never copy to the clipboard or build an Intent instead. In CommandCopyView the HStack's Text gets `Modifier.weight(1f, fill = false)`, so a long command wraps and the share button keeps its size, as in SwiftUI.
- A `UIViewControllerRepresentable` whose makeUIViewController returns `UIActivityViewController(activityItems: items, applicationActivities: nil)` -> a composable with the struct's name and properties (`activityItems: List<Any>`) whose body is `UIActivityViewController(activityItems = activityItems, applicationActivities = null)` from com.moblin.android.platform.swiftui: it shows the share sheet and closes the `.sheet` it is shown in afterwards. makeUIViewController and updateUIViewController are not kept.
- `UIOpenURLContext` is `android.net.Uri`: `urls: Set<UIOpenURLContext>` -> `urls: Set<Uri>`, `url.url` -> `url`, `url.url.isFileURL` -> `url.scheme == "file"`, `url.url.pathExtension` -> `(url.path ?: "").substringAfterLast('.', "")`, `url.path.isEmpty` -> `url.path.isNullOrEmpty()`, `url.query(percentEncoded: false)` -> `url.query`. A `.moblinSettings` file always arrives as a file URI of a readable copy: drop `startAccessingSecurityScopedResource()` and `stopAccessingSecurityScopedResource()`, and `importSettingsFromFile(url: url) { _ in ... }` -> `importSettingsFromFile(url = url.path ?: return) { _ -> }`.
- Location.swift: `class Location(private val context: Context) : LocationListener, com.moblin.android.platform.corelocation.CLLocationManagerDelegate` (Model creates it as `Location(context = AppDelegate.context)`), `CLLocation` -> `android.location.Location` imported `as AndroidLocation`, `@Published var isDenied` -> `val isDenied = MutableStateFlow(false)`, `format(speed: s)` -> `formatSpeed(s.toDouble())` from com.moblin.android.common.various. Updates use `private val manager = context.getSystemService(Context.LOCATION_SERVICE) as LocationManager`: `manager.desiredAccuracy = x` sets a private `var provider` to `manager.getBestProvider(Criteria().apply { accuracy = Criteria.ACCURACY_FINE }, true) ?: LocationManager.GPS_PROVIDER` (`ACCURACY_COARSE` for `.hundredMeters`), `manager.distanceFilter = d` sets a private `var minDistance` Float in metres (`kCLDistanceFilterNone` is 0f), `manager.startUpdatingLocation()` -> a private `startUpdatingLocation()` that returns while neither ACCESS_FINE_LOCATION nor ACCESS_COARSE_LOCATION is granted and otherwise calls `manager.requestLocationUpdates(provider, 0L, minDistance, this, Looper.getMainLooper())`, `manager.stopUpdatingLocation()` -> `manager.removeUpdates(this)`, and `didUpdateLocations` -> `override fun onLocationChanged(location: AndroidLocation)`. `didFailWithError` -> `override fun onProviderDisabled(provider: String)` logging `location: Error, provider $provider disabled`; also override `onProviderEnabled(provider: String)` and `@Suppress("DEPRECATION") override fun onStatusChanged(provider: String?, status: Int, extras: android.os.Bundle?)` with empty bodies, because Android 10 and older call them and crash without them.
- Authorization in Location.swift goes through `private val authorization = com.moblin.android.platform.corelocation.CLLocationManager()`: `manager.delegate = self` -> `authorization.delegate = this`, `manager.requestWhenInUseAuthorization()` -> `authorization.requestWhenInUseAuthorization()` (asks the user once), and `locationManagerDidChangeAuthorization(_ manager: CLLocationManager)` -> `override fun locationManagerDidChangeAuthorization(manager: CLLocationManager)` switching on `manager.authorizationStatus` (`CLAuthorizationStatus.denied, CLAuthorizationStatus.restricted -> isDenied.value = true`), which afterwards calls `startUpdatingLocation()` when `onUpdate != null` and the status is `authorizedWhenInUse` or `authorizedAlways`, so updates start once the user grants the permission, as on iOS.
- `CLBackgroundActivitySession()` and `session.invalidate()` -> `com.moblin.android.platform.corelocation.CLBackgroundActivitySession()` and `invalidate()`; `#available(iOS 17.0, *)` is true. The session keeps location updates coming in Moblin's foreground service while the app is in the background.
- Kotlin shapes these files use: `model.setMuted(value:)`, `model.setQuickButton(type:isOn:)`, `model.makeToast(title:subTitle:)` and `model.makeErrorToast(title:subTitle:)` are Model members (no import); `SettingsQuickButtonType` is in com.moblin.android.various.settings; `takeSnapshot`, `exportToFile`, `restorePurchases`, `purchaseProduct`, `importSettingsWithConfirmation`, `importSettingsFromFile` and `handleSettingsUrlsInWizard` are `fun Model.` extensions imported from com.moblin.android.various.model; `model.stream` is a StateFlow (`val stream by model.stream.collectAsState()`, then `stream.recording.recordingPath`); `ProgressView()` -> `CircularProgressIndicator(modifier = Modifier.size(20.dp), color = formPalette().secondaryLabel, strokeWidth = 2.dp)`.
- ModelSettingsUrl.swift: `fpss` is imported from com.moblin.android.various.settings; `guard !isLive, !isRecording` -> `if (isLive.value || isRecording.value)`; `isLive`, `isRecording`, `presentingStreamImportCollisionConfirmation`, `database.quickButtonsGeneral.twoColumns`, `showName`, `enableScroll` and a quick button's `enabled` and `page` are MutableStateFlow read and written through `.value`; `pendingStreamImportCollisionTitle`, `pendingStreamImportCollisionAction`, `createStreamWizard.presenting` and `presentingSetup` are plain vars; `video.bitrate` is `UInt?` and `assistant.port` is `UShort`, both checked and stored as Int with `.toInt()` (`targetStream.bitrate = bitrate.toInt()`). `String(format: String(localized: "A ‘%@’"), x)` -> `String.format(localized("A ‘%s’"), x)`: java.util.Formatter throws on `%@`.
- RecordingsSettingsView.swift: `FilesLocationView` keeps `path: java.net.URI` (DebugSettingsView passes `model.logsStorage.storageDirectory().toURI()`): `path.path()` -> `path.path`, and RecordingsSettingsView passes `model.recordingsStorage.defaultStorageDirectory().toURI()`, `File(p).toURI()` for the String `p` from `makeRecordingPath(recordingPath)` and `model.replaysStorage.defaultStorageDirectory().toURI()`.
- StoreSettingsView.swift: `store.iconsInStore`, `store.myIcons` and `store.iconImage` are StateFlows collected at the top of each view (`val iconsInStore by store.iconsInStore.collectAsState()`), `Text` is androidx.compose.material3.Text, and `restorePurchases`/`purchaseProduct` are suspend functions called in `scope.launch` with try/catch. `Picker("", selection: $store.iconImage) { ForEach(store.myIcons) { icon in HStack { ... }.tag(icon.image()) } }.pickerStyle(.inline).labelsHidden()` -> `Picker(title = "", selection = iconImage, options = myIcons.map { it.image() }, text = { image -> myIcons.firstOrNull { it.image() == image }?.name ?: image }, pickerStyle = PickerStyle.inline) { image -> store.iconImage.value = image; model.database.iconImage = image; model.updateFaceFilterSettings(); setAppIcon(iconImage = image) }`: the lambda is the `$store.iconImage` binding followed by the `.onChange(of: store.iconImage)` body, `model.database.iconImage` is a plain String var, the options are the tag strings, and asset images are not SF Symbols, so there is no systemImage.
