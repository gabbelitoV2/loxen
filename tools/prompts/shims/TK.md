## Twitch, Kick and chat events (TK, packages com.moblin.android.various, .various.model, .various.settings, .streamingplatforms)
- These Moblin types always exist in Kotlin; never write `TODO()` for them. `ChatHighlightKind` cases are capitalized: `.other` -> `ChatHighlightKind.Other`, `.redemption`, `.firstMessage`, `.newFollower`, `.reply`, `.moderator`, `.remoteControlAssistant`, `.gigantifiedEmote` -> `Redemption`, `FirstMessage`, `NewFollower`, `Reply`, `Moderator`, `RemoteControlAssistant`, `GigantifiedEmote`. `Platform` cases keep Swift's names: `.kick` -> `Platform.kick`, `.twitch` -> `Platform.twitch`.
- `CatPrinterEvent` (various.model) is a sealed class: `.twitchFollow` -> `CatPrinterEvent.TwitchFollow`, `.twitchSubscrptionGift` -> `CatPrinterEvent.TwitchSubscriptionGift`, `.twitchCheer(amount: n)` -> `CatPrinterEvent.TwitchCheer(amount = n)`, `.kickKicks(amount: n)` -> `CatPrinterEvent.KickKicks(amount = n)`; the other cases are the capitalized Swift names.
- `SettingsMacrosEvent` and `MacroVariable` cases are SCREAMING_SNAKE_CASE: `MacroEvent(event: .kickGiftSubscriptions, amount: n)` -> `MacroEvent(event = SettingsMacrosEvent.KICK_GIFT_SUBSCRIPTIONS, amount = n)`; `variables: [.twitchFollowUser: u]` -> `variables = mapOf(MacroVariable.TWITCH_FOLLOW_USER to u)`. Never look them up with `fromRawValue("twitchFollow")`: raw values are the persisted display strings.
- `playAlert(alert: .twitchFollow(event))` and `.kickSubscription(event: e)` -> `playAlert(com.moblin.android.videoeffects.alerts.AlertsEffectAlert.TwitchFollow(event))` and `AlertsEffectAlert.KickSubscription(e)`; `.twitchSubscrptionGift` keeps Swift's spelling.
- SwiftUI system colours are the light-mode values: `.red` `Color(0xFFFF3B30)`, `.orange` `Color(0xFFFF9500)`, `.yellow` `Color(0xFFFFCC00)`, `.green` `Color(0xFF34C759)`, `.mint` `Color(0xFF00C7BE)`, `.cyan` `Color(0xFF32ADE6)`, `.blue` `Color(0xFF007AFF)`, `.indigo` `Color(0xFF5856D6)`, `.purple` `Color(0xFFAF52DE)`, `.pink` `Color(0xFFFF2D55)`, `.gray` `Color(0xFF8E8E93)`, `.white` `Color.White`, `.clear` `Color.Transparent`; never `Color.Cyan`, `Color.Green`, `Color.Blue` or `Color.Gray`.
- A Swift struct copy with a changed field (`var p = post; p.id = n`) -> `post.copy(id = n)`; `ChatPost` is a class, never mutate a post that other lists hold.
- `WatchProtocolChatHighlight`, `WatchProtocolChatHighlightKind` and `WatchProtocolColor` are in `com.moblin.android.moblinwatch.shared`.
- `MapCameraPosition` (`.automatic`, `.region(r)`, `.userLocation(followsHeading:fallback:)`) and `MKDirectionsTransportType` are declared in `ModelNavigation.kt`; keep those declarations when translating `ModelNavigation.swift`. `MKCoordinateRegion` is `com.moblin.android.various.utils.MKCoordinateRegion`.
- `UIPasteboard.general.string = s` -> `AppDelegate.context.getSystemService(ClipboardManager::class.java)?.setPrimaryClip(ClipData.newPlainText(null, s))`. `DCAppAttestService.shared.isSupported` is false on Android. WeatherKit has no counterpart: `weatherManager.getLatestWeather()?.currentWeather` fields are `null`.
- `HttpProxyServer()` and `GoProDevice()` take `AppDelegate.context`. `remoteControlStateChanged(state: .init(stealthMode: on))` -> `remoteControlStateChanged(state = RemoteControlAssistantStreamerState(stealthMode = on))`.
- `Model.latestKnownLocation` is `android.location.Location?`: `location?.distance(from: l)` -> `location?.distanceTo(l)?.toDouble()`, `l.horizontalAccuracy` -> `l.accuracy.toDouble()`. `averageSpeedStartTime.duration(to: now).seconds` -> `(now - averageSpeedStartTime.toEpochMilli()) / 1000.0` (`now` is epoch milliseconds).
- `ModelWebBrowser.swift`: the in-app browser is an `android.webkit.WebView` with `javaScriptEnabled`, `domStorageEnabled` and `javaScriptCanOpenWindowsAutomatically` on. `configuration.setHttpProxy(endpoint: getHttpProxyServerEndpoint())` -> `WKWebViewConfiguration().setHttpProxy(endpoint = getHttpProxyServerNWEndpoint())` (Android's proxy is app-wide, so a fresh configuration applies it), in `setWebBrowserProxy()` only when `webBrowser != null`. `DispatchQueue.main.async { self.loadWebBrowserHome() }` -> `mainScope.launch { WebKitProxy.whenApplied { model.loadWebBrowserHome() } }`. `uiDelegate = webBrowserController` -> `webChromeClient = WebBrowserChromeClient(webBrowserController)`, whose `onJsAlert`, `onJsConfirm` and `onJsPrompt` call the controller's three panel functions and return `true`; keep that class.
