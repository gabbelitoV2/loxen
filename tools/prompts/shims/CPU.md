## Process and device CPU time (CPU, package com.moblin.android.platform.darwin)
- `var usage = rusage()` and `guard getrusage(RUSAGE_SELF, &usage) == 0 else { return }` -> `val usage = rusage()` and `if (getrusage(RUSAGE_SELF, usage) != 0) { return }`; it fills `usage.ru_utime` and `usage.ru_stime` (`timeval`) for the whole process. `timeval.milliseconds` is a `Long`. A stored `rusage?` keeps its type, never `Any?`.
- `host_processor_info(mach_host_self(), PROCESSOR_CPU_LOAD_INFO, &numberOfCpus, &info, &infoCount)` with `guard kerr == KERN_SUCCESS, let info else { return }` -> `val info = host_processor_info(mach_host_self(), PROCESSOR_CPU_LOAD_INFO) ?: run { cpuUsage = appCpuUsage; return }` in `ResourceUsage.updateCpuUsage`, `?: return` elsewhere; `numberOfCpus` -> `info.numberOfCpus`, `UInt32(bitPattern: info[i])` -> `info[i].toUInt()`, and drop `infoCount` and the `vm_deallocate` defer. `Int(CPU_STATE_MAX)`, `Int(CPU_STATE_USER)` and the other `CPU_STATE_*` -> the `Int` constants as they are. It returns null on Android 8 and later, where apps cannot read the device's CPU time.
- `var info = task_vm_info_data_t()`, `var count = ...` and `let kerr = withUnsafeMutablePointer(to: &info) { ... task_info(mach_task_self_, task_flavor_t(TASK_VM_INFO), $0, &count) }` -> `val info = task_vm_info_data_t()` and `val kerr = task_info(mach_task_self_, TASK_VM_INFO, info)`; drop `count` and the pointer rebinding. `KERN_SUCCESS` is an `Int`, `info.phys_footprint` a `ULong` in bytes (`/ 1024u / 1024u`). Never `android.os.Debug`.
