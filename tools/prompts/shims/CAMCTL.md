## Manual camera controls (CAMCTL, package com.moblin.android.platform.avfoundation)
- `device.focusMode = .autoFocus` -> `device.focusMode = AVCaptureDevice.FocusMode.autoFocus`; likewise `AVCaptureDevice.ExposureMode.custom`/`.autoExpose`/`.continuousAutoExposure`/`.locked` and `AVCaptureDevice.WhiteBalanceMode.locked`/`.continuousAutoWhiteBalance`. Set them between `lockForConfiguration()` and `unlockForConfiguration()` as in Swift; they reach the camera at the unlock and never throw.
- `device.focusPointOfInterest = CGPoint(x: x, y: y)` -> `device.focusPointOfInterest = PointF(x, y)` (`android.graphics.PointF`), same for `exposurePointOfInterest`. The point uses the iOS coordinates (landscape, home button right); keep Swift's orientation conversion before it.
- `device.setFocusModeLocked(lensPosition: x)`, `device.setExposureModeCustom(duration: d, iso: i) { _ in }`, `device.setExposureTargetBias(b)`, `device.setWhiteBalanceModeLocked(with: g)` -> `setFocusModeLocked(lensPosition = x)`, `setExposureModeCustom(duration = d, iso = i) { }` (`d` is `Long` microseconds), `setExposureTargetBias(b)`, `setWhiteBalanceModeLocked(with = g)`. `AVCaptureDevice.currentLensPosition`, `currentISO`, `currentExposureDuration` and `currentWhiteBalanceGains` keep their names.
- `isLockingFocusWithCustomLensPositionSupported`, `isExposureModeSupported(.custom)`, `isLockingWhiteBalanceWithCustomDeviceGainsSupported`, `isFocusPointOfInterestSupported`, `isExposurePointOfInterestSupported`, `isFocusModeSupported(_:)`, `isWhiteBalanceModeSupported(_:)`, `activeFormat.minISO`/`maxISO`/`minExposureDuration`/`maxExposureDuration`, `min`/`maxExposureTargetBias` and `maxWhiteBalanceGain` read the real camera: translate them as they are, never as `false` or constants.
