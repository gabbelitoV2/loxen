## AppAuth (OID, package com.moblin.android.platform.appauth)
- `OIDAuthorizationService.discoverConfiguration(forIssuer: issuer) { configuration, error in ... }` -> `OIDAuthorizationService.discoverConfiguration(forIssuer = issuer) { configuration, error -> ... }` (`OIDServiceConfiguration?`, `Throwable?`, called on the main thread; `issuer` is a String such as `youTubeIssuer`). `nonisolated(unsafe) let x = y` -> use `y`; `MainActor.assumeIsolated { body }` -> `body`.
- `OIDAuthorizationRequest(configuration:clientId:clientSecret:scopes:redirectURL:responseType:additionalParameters:)` -> the constructor with the same parameter names (`scopes: List<String>?`, `redirectURL: String`, `additionalParameters: Map<String, String>?`); `OIDResponseTypeCode` keeps its name.
- `guard let userAgent = OIDExternalUserAgentIOS(presenting: vc) else { return }` -> `val userAgent = OIDExternalUserAgentIOS(presenting = vc) ?: return`, with `vc` the `com.moblin.android.platform.uikit.UIViewController` from `getRootViewController()`; translate only the `#else` branch of `#if targetEnvironment(macCatalyst)`.
- `OIDAuthState.authState(byPresenting: request, externalUserAgent: userAgent, callback: cb)` -> `OIDAuthState.authState(byPresenting = request, externalUserAgent = userAgent, callback = cb)`: it opens a Custom Tab, exchanges the code for tokens and returns an `OIDExternalUserAgentSession`. `OIDAuthStateAuthorizationCallback` is the type `(OIDAuthState?, Throwable?) -> Unit`, called on the main thread.
- `authState.performAction { accessToken, idToken, error in ... }` -> `authState.performAction { accessToken, idToken, error -> ... }` (refreshes the token when needed; main thread). `authState.isAuthorized` and `authState.lastTokenResponse?.accessTokenExpirationDate` (`java.time.Instant?`) keep their names.
- A property or parameter of type `OIDAuthState?` or `(any OIDExternalUserAgentSession)?` stays `OIDAuthState?` or `OIDExternalUserAgentSession?`, never `Any?`. `try? NSKeyedArchiver.archivedData(withRootObject: authState, requiringSecureCoding: false)` -> `authState.archivedData()`; `try? NSKeyedUnarchiver.unarchivedObject(ofClass: OIDAuthState.self, from: data)` -> `OIDAuthState.unarchivedObject(from = data)` (null when unreadable).
