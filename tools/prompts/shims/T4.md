## Preview layer and readback (T4, package com.moblin.android.platform.video)

- `PreviewView.layer` is an `AVSampleBufferDisplayLayer`: the extension property `layer` from `com.moblin.android.platform.video` (add `import com.moblin.android.platform.video.layer`). Keep Swift's calls as they are: `layer.enqueue(sampleBuffer)`, `layer.flush()`, `layer.flushAndRemoveImage()`, and `layer.status == .failed` -> `layer.status == AVSampleBufferDisplayLayer.Status.failed`. Never declare a `layer` member on `PreviewView`.
- `layer.videoGravity = x`, `layer.backgroundColor = ...` and `backgroundColor = .black` in `PreviewView` -> drop them. The layer reads `PreviewView.videoGravity` (`resizeAspect` fit, `resizeAspectFill` fill, `resize` stretch) on every draw and clears to black itself. `layer.setAffineTransform(CGAffineTransformMakeScale(x, 1))` -> `scaleX = x` on the `PreviewView` (the default pivot is the view centre and follows layout, like the layer's anchor point); never a `setScale` pivot computed from `width`/`height`, which is 0 before layout.
- A completion handler that Swift marks `@MainActor`, or runs in `DispatchQueue.main.async`, runs on the main thread: `CoroutineScope(Dispatchers.Main.immediate).launch { ... }`, never `processorPipelineQueue.launch`.
- A camera preview layer (`AVCaptureVideoPreviewLayer`, which is `PreviewView`) is fed by the capture engine through `layer.drawOnPipeline(buffer)`; generated code never calls it.
- `VideoEffectInfo.presentationTimeStamp` is the sample's `presentationTimeUs` (microseconds), never seconds.
- Outside Moblin/VideoEffects/ and VideoEffectsProcessor.swift, `CIImage(cvPixelBuffer:)` scaled to a 400 pixel long side plus `UIImage.jpegData(compressionQuality:)` -> `imageBuffer.jpegData(longSide = 400, compressionQuality = 0.3f)`. `context.createCGImage(CIImage(cvPixelBuffer: b), from:)` plus `UIImage(cgImage:)` -> `b.toBitmap()`.
