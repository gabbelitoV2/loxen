## Pixel buffer pool lifetime (L2, package com.moblin.android.platform.video)
- Assigning `nil` or another pool to a stored `CVPixelBufferPool?` property (`pool = nil`, `self.bufferedPool = nil`, the `pool = nil` before `CVPixelBufferPoolCreate(..., &pool)`) -> `pool = com.moblin.android.platform.video.swapPool(pool, null)` (or `swapPool(pool, newPool)`). It frees the replaced pool's buffers as ARC does; a plain `pool = null` leaves them to the garbage collector.
