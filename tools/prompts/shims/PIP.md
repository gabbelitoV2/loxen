## Picture in picture (PIP, package com.moblin.android.platform.avkit)
- `AVPictureInPictureController`, `AVPictureInPictureController.ContentSource`, `AVPictureInPictureSampleBufferPlaybackDelegate` and `CMVideoDimensions` (`width`, `height` Int) come from the shim; never declare stand-ins or use `android.app.PictureInPictureParams`. `var pipController: AVPictureInPictureController?` keeps that type, never `Any?`.
- `AVPictureInPictureController.isPictureInPictureSupported()`, `AVPictureInPictureController(contentSource: s)` -> `AVPictureInPictureController(contentSource = s)`, `canStartPictureInPictureAutomaticallyFromInline` and `contentSource` (read and set, `nil` -> `null`) keep their shape. `ContentSource(sampleBufferDisplayLayer: view.layer, playbackDelegate: self)` -> `AVPictureInPictureController.ContentSource(sampleBufferDisplayLayer = view.layer, playbackDelegate = ModelPictureInPicturePlaybackDelegate(this))`, `layer` from `com.moblin.android.platform.video`.
- `extension Model: AVPictureInPictureSampleBufferPlaybackDelegate` -> each method as a `fun Model.` extension whose first parameter is `pictureInPictureController: AVPictureInPictureController`, plus `private class ModelPictureInPicturePlaybackDelegate(private val model: Model) : AVPictureInPictureSampleBufferPlaybackDelegate` forwarding every override to them. `CMTimeRange(start: .negativeInfinity, duration: .positiveInfinity)` -> `CMTimeRange(start = Long.MIN_VALUE, duration = Long.MAX_VALUE)` from `com.moblin.android.platform.avfoundation`; `skipByInterval` is a `Long` in microseconds.
- The Android window has no playback controls: only `didTransitionToRenderSize` is ever called on the delegate.
