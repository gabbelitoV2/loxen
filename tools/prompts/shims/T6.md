## VideoToolbox and format description shims (T6, package com.moblin.android.platform.videotoolbox)

- `VTCompressionSession` is the class `com.moblin.android.platform.videotoolbox.VTCompressionSession` (a hardware MediaCodec encoder fed through an EGL input surface). Keep Swift's calls: `VTCompressionSessionCreate(allocator:width:height:codecType:encoderSpecification:imageBufferAttributes:compressedDataAllocator:outputCallback:refcon:compressionSessionOut:)` -> `var (status, session) = VTCompressionSessionCreate(width = w, height = h, codecType = format.codecType, imageBufferAttributes = attributes)`, which returns `Pair<Int, VTCompressionSession?>`; `codecType` is the MIME string (`"video/avc"` or `"video/hevc"`) and `imageBufferAttributes` is a `Map<String, Any>` keyed by the `kCVPixelBuffer*Key` constants.
- `VTSessionSetProperties(session, propertyDictionary: dict as CFDictionary)` -> `VTSessionSetProperties(session, dict)` with a `Map<String, Any>` keyed by the `VTSessionPropertyKey.value` strings. `VTCompressionSessionPrepareToEncodeFrames(session)`, `VTCompressionSessionInvalidate(session)` keep their names.
- `VTCompressionSessionEncodeFrame(session, imageBuffer:presentationTimeStamp:duration:frameProperties:infoFlagsOut:outputHandler:)` -> `VTCompressionSessionEncodeFrame(session, imageBuffer, presentationTimeStamp, duration, frameProperties, outputHandler)`; drop `infoFlagsOut`. Times are `Long` microseconds and `.invalid` is `kCMTimeInvalidUs`. It must run on `processorPipelineQueue`. `VTCompressionOutputHandler` is `(status: Int, infoFlags: Int, sampleBuffer: MediaSample?) -> Unit`, called on an encoder thread; the output `MediaSample` holds AVCC data, `decodeTimeStampUs` and the encoder's `MediaFormat` in `format` (Swift `sampleBuffer.formatDescription`).
- The `VTCompressionSession` extension methods `prepareToEncodeFrames()`, `encodeFrame(imageBuffer, presentationTimeStamp =, duration =) { status, _, sampleBuffer -> }`, `invalidate()` and `setProperties(properties: List<VTSessionProperty>)` live in `com.moblin.android.media.haishinkit.extension`.
- `OSStatus` is `Int`. `noErr`, `kVTPropertyNotSupportedErr`, `kVTParameterErr`, `kVTInvalidSessionErr`, `kVTCouldNotFindVideoEncoderErr` and `kVTEncodeInfo_FrameDropped` are `Int` constants, and `kVTProfileLevel_H264_Baseline_AutoLevel`, `kVTProfileLevel_H264_Main_AutoLevel`, `kVTProfileLevel_H264_High_AutoLevel`, `kVTProfileLevel_HEVC_Main_AutoLevel`, `kVTProfileLevel_HEVC_Main10_AutoLevel` and `kVTEncodeFrameOptionKey_ForceKeyFrame` are the VideoToolbox strings; import them from `com.moblin.android.platform.videotoolbox`, never declare them. `kVTProfileLevel_*` is never `MediaCodecInfo.CodecProfileLevel.*.toString()`.
- `CMFormatDescription` is `android.media.MediaFormat`. `CMFormatDescriptionGetExtension(fd, extensionKey: kCMFormatDescriptionExtension_SampleDescriptionExtensionAtoms)` -> `CMFormatDescriptionGetExtension(fd, kCMFormatDescriptionExtension_SampleDescriptionExtensionAtoms)`, which returns a `Map<String, ByteArray>` with `"avcC"` or `"hvcC"`; `formatDescription.atoms()` (from `com.moblin.android.common.various`) wraps it, so `atoms["avcC"] as? Data` -> `atoms["avcC"]`. `CMFormatDescriptionGetExtensions(fd)` -> `CMFormatDescriptionGetExtensions(fd)` (`Map<String, Any>?`).
- `CMFormatDescriptionEqual(a, otherFormatDescription: b)` -> `CMFormatDescriptionEqual(a, b)`, a content comparison; never compare two `MediaFormat`s with `==`.
- Reading a `ByteBuffer` stored in a `MediaFormat` (`csd-0`, `avcC`, `hvcC`) always goes through `getByteBuffer(key)!!.duplicate()`, never `get()` on the stored buffer.
