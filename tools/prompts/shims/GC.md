## Game controller (LOXEN, package com.moblin.android.platform.gamecontroller)
- `GCController`, `GCExtendedGamepad`, `GCControllerButtonInput` and `GCControllerDirectionPad` -> the same-named shims, never android.view.InputDevice, KeyEvent or MotionEvent.
- In `Model`, write these lines fully qualified and without imports, exactly like this: `var gameControllers: [GCController?] = []` -> `var gameControllers: MutableList<com.moblin.android.platform.gamecontroller.GCController?> = mutableListOf()`; `addObserver(.GCControllerDidConnect, #selector(f))` -> `com.moblin.android.platform.core.NotificationCenter.default.addObserver(this, com.moblin.android.platform.gamecontroller.GCController.didConnectNotification, null) { f(it) }`, and `.GCControllerDidDisconnect` the same with `didDisconnectNotification`, never Model's `addObserver(name, selector)`; `GCController.startWirelessControllerDiscovery {}` -> `com.moblin.android.platform.gamecontroller.GCController.startWirelessControllerDiscovery {}`. Controllers that are already connected are posted after discovery starts.
- The handler takes `notification: Notification`; `notification.object as? GCController` -> `notification.obj as? GCController`.
- `extendedGamepad` is nullable. `button.pressedChangedHandler = { button, value, pressed in }` -> `button.pressedChangedHandler = { button, value, pressed -> }` with `(GCControllerButtonInput, Float, Boolean)`; `stick.valueChangedHandler = { _, x, y in }` -> `stick.valueChangedHandler = { _, x, y -> }` with `(GCControllerDirectionPad, Float, Float)`. `sfSymbolsName` is `String?`. Handlers run on the main thread.
