## Media readers, speech and animated images (E5, packages com.moblin.android.platform.avfoundation and com.moblin.android.platform.sdwebimage)
- AVAsset(url:), AVAssetTrack, AVAssetReader (throws AVError), AVAssetReaderTrackOutput, CMTimeRange (Long microseconds, labels start/duration/end) -> the shims. `AVAsset(url: u)` -> `AVAsset(url = u)` (u a String path, java.io.File or java.net.URI). `asset.loadTracks(withMediaType: .video) { tracks, error in }` -> `asset.loadTracks(withMediaType = AVMediaType.video) { tracks, error -> }` (completion on a background thread). `asset.duration()` -> `asset.duration()` (a member, Double seconds). `try? AVAssetReader(asset: a)` -> `runCatching { AVAssetReader(asset = a) }.getOrNull()`. `reader.add(o)`, `startReading()` (Boolean), `cancelReading()`, `timeRange` and `status` (`AVAssetReader.Status.reading`) keep their names.
- `trackOutput.copyNextSampleBuffer()` returns MediaSample? and blocks; call it only on the reader's own queue, never on processorPipelineQueue. Video samples carry `imageBuffer`; audio samples carry 16-bit PCM: `sampleBuffer.dataBuffer?.data` -> `sampleBuffer.data`, `sampleBuffer.presentationTimeStamp.seconds` -> `sampleBuffer.presentationTimeUs / 1_000_000.0`. Output settings are `Map<String, Any>`: `AVFormatIDKey: kAudioFormatLinearPCM` -> `AVFormatIDKey to kAudioFormatLinearPCM` (a MIME String); `AVLinearPCMBitDepthKey`, `AVLinearPCMIsFloatKey`, `AVLinearPCMIsBigEndianKey` are String keys in the same package; `kCVPixelBufferIOSurfacePropertiesKey: NSDictionary()` -> `kCVPixelBufferIOSurfacePropertiesKey to emptyMap<String, Any>()`.
- AVSpeechSynthesizer, AVSpeechUtterance(string:), AVSpeechSynthesisVoice(identifier:), AVSpeechSynthesisVoice.speechVoices(), AVSpeechBoundary -> the shims; never android.speech.tts directly. `AVSpeechSynthesisVoice(identifier: i)` -> `AVSpeechSynthesisVoice(identifier = i)` (nullable). `func speechSynthesizer(_:didStart:)`, `(_:didFinish:)` and `(_:didCancel:)` of AVSpeechSynthesizerDelegate -> `override fun speechSynthesizerDidStart(synthesizer: AVSpeechSynthesizer, utterance: AVSpeechUtterance)`, `speechSynthesizerDidFinish(...)` and `speechSynthesizerDidCancel(...)`. Moblin's `createSpeechSynthesizer()` -> `AVSpeechSynthesizer().also { it.usesApplicationAudioSession = false }` (the Kotlin function of that name returns TextToSpeech and is for chat text-to-speech only).
- SDAnimatedImage(data:) (nullable), animatedImageFrameCount, animatedImageLoopCount, animatedImageFrame(at:) (Bitmap?), animatedImageDuration(at:) (Double seconds) -> platform.sdwebimage; indices and counts are Int.
- Moblin settings objects have no objectWillChange in Kotlin: `settings.objectWillChange.sink { [weak self] _ in self?.f() }` -> drop the subscription, and call `f()` on main at the end of every method that mutates that settings object (for ChatEffect: `setSettings` after `settings.update(other = …)`).
