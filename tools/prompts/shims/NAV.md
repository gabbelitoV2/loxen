## Navigation map, place search and directions (NAV, packages com.moblin.android.platform.mapkit and com.moblin.android.platform.swiftui)
- `MapCameraPosition`, `MKDirectionsTransportType`, `MKDirections`, `MKRoute`, `MKMapItem`, `MKLocalSearch`, `MKMapItemRequest`, `PlaceDescriptor`, `Map`, `MapReader`, `Marker`, `MapPolyline`, `UserAnnotation`, `MapInteractionModes` and `CoordinateSpace` are imported from com.moblin.android.platform.mapkit: never declare them, never type them `Any`, never write `TODO()` or `Unit` for them, and leave the unsupported list empty. `MKCoordinateRegion`, `MKCoordinateSpan` and `CLLocationCoordinate2D` are the data classes in com.moblin.android.various.utils: `.init(center: c, span: s)` -> `MKCoordinateRegion(center = c, span = s)`.
- `Navigation` keeps typed flows: `MutableStateFlow<MapCameraPosition>(MapCameraPosition.automatic)`, `MutableStateFlow<MKRoute?>(null)`, `MutableStateFlow<MKMapItem?>(null)` for `destination` and `longPressLocation`, `MutableStateFlow<List<MKMapItem>>(emptyList())`. `.region(r)` -> `MapCameraPosition.region(r)`, `.userLocation(followsHeading: h, fallback: .region(r))` -> `MapCameraPosition.userLocation(followsHeading = h, fallback = MapCameraPosition.region(r))`; `toSystem()` returns `MKDirectionsTransportType.walking` (`.cycling`, `.automobile`).
- `MKDirections.Request()` keeps `source`, `destination` and `transportType`; `.forCurrentLocation()` -> `MKMapItem.forCurrentLocation()`. `MKDirections(request: r).calculate { response, _ in guard let response else { return } ... }` -> `MKDirections(request = r).calculate { response, _ -> if (response == null) return@calculate ... }`. The handler runs on the main thread: drop `nonisolated(unsafe)` and write `DispatchQueue.main.async { self.route = route }` as `this.route.value = route`; `response.routes.first` -> `response.routes.firstOrNull()`.
- `MKLocalSearch.Request()` keeps `naturalLanguageQuery` and `region`; `MKLocalSearch(request: r).start { response, _ in ... }` -> `MKLocalSearch(request = r).start { response, _ -> if (response == null) return@start; navigation.searchResults.value = response.mapItems }` (main thread).
- `PlaceDescriptor(representations: [.coordinate(c)], commonName: nil)` -> `PlaceDescriptor(representations = listOf(PlaceDescriptor.PlaceRepresentation.coordinate(c)), commonName = null)`, `MKMapItemRequest(placeDescriptor = p)`. `Task { a = try? await request.mapItem; b }` -> `scope.launch { a = runCatching { request.mapItem() }.getOrNull(); b }` with `val scope = rememberCoroutineScope()` in the calling composable.
- `item.location.coordinate` -> `item.location.coordinate` (import `com.moblin.android.platform.mapkit.coordinate`); `item.name` is `String?`; MKMapItem compares by identity. `route.expectedTravelTime` is Double seconds: `Duration.seconds(t).format()` -> `t.toDuration(DurationUnit.SECONDS).format()` (`format` from com.moblin.android.common.various).
- `MapReader { proxy in Map(position: $navigation.cameraPosition, interactionModes: [.pan, .rotate, .zoom], selection: $navigation.destination) { C }.onMapCameraChange { context in A }.frame(maxWidth: w, maxHeight: h).clipShape(RoundedRectangle(cornerRadius: 7)).padding(.trailing, 3).gesture(LongPressGesture(...).sequenced(before: DragGesture(...)).onEnded { ... proxy.convert(location, from: .local) ... f(coordinate: coordinate) }) }` with `.onChange(of: navigation.destination) { _ in navigation.updateDirections() }` -> `MapReader { proxy -> Map(position = cameraPosition, onPositionChange = { navigation.cameraPosition.value = it }, selection = destination, onSelectionChange = { navigation.destination.value = it; navigation.updateDirections() }, modifier = Modifier.padding(end = 3.dp).clip(RoundedCornerShape(7.dp)).widthIn(max = w.dp).heightIn(max = h.dp), interactionModes = setOf(MapInteractionModes.pan, MapInteractionModes.rotate, MapInteractionModes.zoom), onMapCameraChange = { context -> A }, onLongPress = { location -> proxy.convert(location, from = CoordinateSpace.local)?.let { f(coordinate = it) } }) { C } }`. `context.region` is the `MKCoordinateRegion`. Map fills its frame; the modifier replaces `.frame`, `.clipShape`, `.padding` and `.gesture`.
- Map content `C`: `UserAnnotation()` -> `UserAnnotation()`. `Marker(coordinate: c) { L }.tag(t)` -> `Marker(coordinate = c, tag = t) { L }`. `ForEach(items, id: \.self) { item in Marker(coordinate: c) { L } }` -> `items.forEach { item -> key(item) { Marker(coordinate = c, tag = item) { L } } }` (the ForEach id is the tag). `if let route = navigation.route { MapPolyline(route).stroke(.blue, lineWidth: 5) }` -> `route?.let { MapPolyline(it, stroke = Color(0xFF007AFF), lineWidth = 5.0) }`. A marker label is plain `Text(...)`; the Marker styles it.
- `.onChange(of: navigationSettings.followUser)` and `.onChange(of: navigationSettings.followHeading)`, both calling `navigation.updateCameraPosition(settings: navigationSettings)` -> one `LaunchedEffect(followUser, followHeading) { navigation.updateCameraPosition(settings = navigationSettings) }` on the collected values. `.onAppear` -> `LaunchedEffect(Unit)` whose body is statements, never an `if`/`else` or `?.let` expression as its last line: `if let (latitude, longitude) = model.getLatestKnownLocation() { B }` -> `val location = model.getLatestKnownLocation(); if (location != null) { val (latitude, longitude) = location; B }` (a `Pair<Double, Double>?` from the extension `com.moblin.android.various.model.getLatestKnownLocation`, which must be imported). `navigation.timer.startSingleShot(timeout: 5)` -> `startSingleShot(timeout = 5.0)`. `NavigationTransportType.allCases` -> `NavigationTransportType.entries`.
- `SettingsNavigation.followUser` and `followHeading` are read-only `StateFlow<Boolean>`: `navigationSettings.followUser = v` -> `(navigationSettings.followUser as MutableStateFlow<Boolean>).value = v`.
- Every composable that reads `navigation.isSmall`, `route`, `destination`, `longPressLocation`, `searchResults`, `searchText`, `transportType` or `cameraPosition` collects it with `collectAsState()` in its own body and passes the collected value to its local helpers (`mapSide`, `minMaxButtonIcon`, `offset`); never read `.value` in a composable body, or the map does not resize and the icon does not change.
- `.glassEffect()` -> `Modifier.glassEffect()` from com.moblin.android.platform.swiftui (a capsule), at the Swift position in reversed modifier order: `.frame(width: 12, height: 12).padding().glassEffect().padding(.trailing, 10)` -> `Modifier.padding(end = 10.dp).glassEffect().padding(16.dp).size(12.dp)`. Never drop it or write `.then(Modifier)`.
- `Button { a } label: { V.modifiers }` -> `Button(action = { a }) { V }` from com.moblin.android.platform.swiftui with the label's modifiers on V; `.foregroundStyle(.primary)` is `formPalette().label`. The images and the Picker spill out of their 12- and 35-point frames as in SwiftUI: the frame is `Box(Modifier...size(...), contentAlignment = Alignment.Center)`, and every view inside it starts its modifier with `Modifier.wrapContentSize(unbounded = true)`: `SystemImage(name, fontSize = 17.sp, modifier = Modifier.wrapContentSize(unbounded = true), tint = formPalette().label)`, the `SystemImage` of `ImageLocationView` and the `Box` of `ImageConeView` (`Modifier.wrapContentSize(unbounded = true).offset(...)` with the Swift offset), and `Box(Modifier.wrapContentSize(unbounded = true)) { Picker(...) }`.
- `TextField("T", text: $navigation.searchText).frame(maxWidth: 300, maxHeight: 20).padding(12).glassEffect().onSubmit { a }` -> `BasicTextField(value = searchText, onValueChange = { navigation.searchText.value = it }, singleLine = true, textStyle = TextStyle(fontSize = 17.sp, lineHeight = 20.sp, color = formPalette().label), cursorBrush = SolidColor(formPalette().accent), keyboardOptions = KeyboardOptions(imeAction = ImeAction.Search), keyboardActions = KeyboardActions(onSearch = { a }), modifier = Modifier.glassEffect().padding(12.dp).widthIn(max = 300.dp).fillMaxWidth().heightIn(max = 20.dp), decorationBox = { inner -> Box(contentAlignment = Alignment.CenterStart) { if (searchText.isEmpty()) Text(localized("T"), style = TextStyle(fontSize = 17.sp, lineHeight = 20.sp, color = formPalette().secondaryLabel)); inner() } })`; never OutlinedTextField.
