## Asset writer shims for recording (T8, package com.moblin.android.platform.avfoundation)

- `AVAssetWriter(contentType: .mpeg4Movie)` -> `AVAssetWriter(contentType = UTType.mpeg4Movie)`, which writes fragmented MP4 through its delegate only (there is no output file). Keep `shouldOptimizeForNetworkUse`, `outputFileTypeProfile = AVFileTypeProfile.mpeg4AppleHLS`, `delegate` and `initialSegmentStartTime = 0`; `preferredOutputSegmentInterval = CMTime(seconds: 2)` -> `preferredOutputSegmentInterval = 2_000_000` (`Long` microseconds).
- `writer.add(input)`, `writer.startWriting()`, `writer.finishWriting { ... }` (the completion runs on a background thread) and `writer.cancelWriting()` keep their names; `writer.startSession(atSourceTime: .zero)` -> `writer.startSession(atSourceTime = 0L)`; `writer.inputs.count` -> `writer.inputs.size`; `writer.status == .writing` -> `writer.status == AVAssetWriter.Status.writing`; `writer.error?.localizedDescription ?? ""` -> `writer.error?.localizedMessage ?: ""`.
- `AVAssetWriterInput(mediaType: .video, outputSettings: s, sourceFormatHint: fd)` -> `AVAssetWriterInput(mediaType = AVMediaType.video, outputSettings = s, sourceFormatHint = fd)` with `s` a `Map<String, Any>` and `fd` a `MediaFormat?`. Keep `expectsMediaDataInRealTime`, `isReadyForMoreMediaData`, `markAsFinished()` and `append(sampleBuffer)`, which returns `false` on failure and never throws. The video input takes raw `MediaSample`s (`imageBuffer`) and encodes them itself; the audio input takes 16-bit PCM and encodes AAC.
- `writer.inputReceiver(for: input)` -> `writer.inputReceiver(input)` (type `AVAssetWriterInput.SampleBufferReceiver`); `try receiver.appendImmediately(CMReadySampleBuffer(unsafeBuffer: sb))` -> `receiver.appendImmediately(sb)`, which throws `AVError`. `if #available(iOS 26, *)` around it: translate the else branch.
- `extension X: AVAssetWriterDelegate` -> `X` implements `AVAssetWriterDelegate` in its class header, and `func assetWriter(_:didOutputSegmentData:segmentType:segmentReport:)` -> `override fun assetWriter(writer: AVAssetWriter, didOutputSegmentData: ByteArray, segmentType: AVAssetSegmentType, segmentReport: AVAssetSegmentReport?)`. `.initialization`/`.separable` -> `AVAssetSegmentType.initialization`/`AVAssetSegmentType.separable` (an enum, so no `default` branch). `segmentReport?.trackReports.first` -> `segmentReport?.trackReports?.firstOrNull()`; its `earliestPresentationTimeStamp` and `duration` are `Long` microseconds, so `.seconds` -> `/ 1_000_000.0`.
- `AVVideoCodecKey`, `AVVideoWidthKey`, `AVVideoHeightKey`, `AVVideoCompressionPropertiesKey`, `AVVideoAverageBitRateKey`, `AVVideoMaxKeyFrameIntervalDurationKey`, `AVFormatIDKey`, `AVSampleRateKey`, `AVNumberOfChannelsKey` and `AVEncoderBitRateKey` are `String` constants equal to the `MediaFormat` keys (`"mime"`, `"width"`, `"bitrate"`, ...), so use them as `when` subjects and map keys. `AVVideoCodecType.h264`/`.hevc` -> `AVVideoCodecType.h264`/`AVVideoCodecType.hevc` (MIME strings); `Int(kAudioFormatMPEG4AAC)` -> `MediaFormat.MIMETYPE_AUDIO_AAC`, never a number.
- In `Recorder`, `url: URL?` stays a `String?` path, `FileHandle(forWritingAtPath: url.path)` -> `runCatching { FileOutputStream(file) }.getOrNull()`, `fileHandle?.write(data)` goes in `try`/`catch (error: IOException)`, and a handle that is replaced or set to `nil` is closed first.
