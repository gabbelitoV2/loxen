## librist (RIST, package com.moblin.android.platform.rist)

- `import Rist` -> import the used names from `com.moblin.android.platform.rist`: `RistSenderContext`, `RistSenderContextDelegate`, `RistPeer`, `RistStats`, `RistSenderStats`, `RistReceiverContext`, `RistReceiverContextDelegate`, `ristVersion`. Never declare them, `RistNative`, `external` functions, `System.loadLibrary` or `rist_*` C calls.
- `RistSenderContext()` and `RistReceiverContext(inputUrl: u)` -> `RistSenderContext()` and `RistReceiverContext(inputUrl = u)`. Both return `null` like the failable Swift inits (`guard let x = ... else` -> `?: run { ...; return }`). `profile:` is an `Int` (`RIST_PROFILE_SIMPLE`, `RIST_PROFILE_MAIN`, `RIST_PROFILE_ADVANCED`), main by default.
- `delegate`, `start()` (`Boolean`), `stop()`, `addPeer(url = u)` (`RistPeer?`), `send(data = d)` and `send(dataPointer = bytes, count = n)` (`Boolean`, `UnsafeRawBufferPointer` is a `ByteArray`) keep their names. `delegate` is a plain nullable var; every call after `stop()` does nothing.
- `RistPeer` is destroyed by its Swift `deinit`: call `peer.close()` wherever Swift drops the last reference (`removeAll`, `removeAll(where:)`, replacing it); a class that owns a `RistPeer` closes it in its own `close()`. `setWeight(weight = w)` takes a `UInt` and `getId()` returns a `UInt`.
- `RistSenderContextDelegate`: `ristSenderContextStats(context: RistSenderContext, stats: RistStats)`, `ristSenderContextPeerConnected(context: RistSenderContext, peerId: UInt)`, `ristSenderContextPeerDisconnected(context: RistSenderContext, peerId: UInt)`, called on a librist thread.
- `RistStats(sender)`; `RistSenderStats` is a data class with `peerId: UInt`, `bandwidth`, `retryBandwidth`, `sentPackets`, `receivedPackets`, `retransmittedPackets: ULong`, `quality: Double` and `rtt: UInt`.
- `RistReceiverContextDelegate`: `ristReceiverContextConnected(virtualDestinationPort: Int)`, `ristReceiverContextDisconnected(virtualDestinationPort: Int)`, `ristReceiverContextReceivedData(virtualDestinationPort: Int, packets: List<ByteArray>)`; `UInt16` virtual ports are `Int`.
- A `miface=<NWInterface.name>` query item in a sender peer URL binds the peer to that Android network, so bonding URLs are built exactly as in Swift; `addPeer` returns `null` when the interface is gone.
- `RistStream.addMoblink(endpoint:id:name:)`, `removeMoblink(endpoint:)` and `makeRistMoblinkBondingUrl(_:_:)` keep the `NWEndpoint` of `com.moblin.android.platform.network`.
