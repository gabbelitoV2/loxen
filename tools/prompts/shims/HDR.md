## Pixel formats, colour and CPU access to pixel buffers (HDR, packages com.moblin.android.platform.video, .videotoolbox, .coreimage, .coregraphics and .avfoundation)

- `CVPixelBufferCreate(nil, w, h, f, attributes as CFDictionary, &pixelBuffer)` -> `val pixelBuffer = CVPixelBufferCreate(null, w, h, f, attributes)` (a `CVPixelBuffer?`; `attributes` a `Map<String, Any>?`, `[kCVPixelBufferIOSurfacePropertiesKey: [:]]` -> `mapOf(kCVPixelBufferIOSurfacePropertiesKey to emptyMap<String, Any>())`). `CVPixelBufferGetPixelFormatType(b)` returns the requested format, 10-bit `kCVPixelFormatType_420YpCbCr10BiPlanarFullRange`/`VideoRange` included.
- `CVPixelBufferLockBaseAddress(b, .readOnly)` -> `CVPixelBufferLockBaseAddress(b, CVPixelBufferLockFlags.readOnly)` and `[]` -> `0`, the same for `CVPixelBufferUnlockBaseAddress`; `defer { unlock }` -> `try { ... } finally { unlock }`. `CVPixelBufferGetBaseAddressOfPlane(b, i)!.assumingMemoryBound(to: UInt8.self)` -> `CVPixelBufferGetBaseAddressOfPlane(b, i)!!`, a little-endian `java.nio.ByteBuffer` over the plane, so Swift `p[n]` (a `UInt8`) -> `(p.get(n).toInt() and 0xFF)`. `CVPixelBufferGetBytesPerRowOfPlane(b, i)`, `CVPixelBufferGetWidthOfPlane(b, i)` and `CVPixelBufferGetHeightOfPlane(b, i)` return `Int`.
