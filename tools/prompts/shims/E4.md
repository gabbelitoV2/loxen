## WebKit (E4, package com.moblin.android.platform.webkit)
- WKWebView, WKWebViewConfiguration, WKUserContentController, WKUserScript, WKUserScriptInjectionTime, WKScriptMessageHandler, WKScriptMessage, WKSnapshotConfiguration, WKWebsiteDataStore, ProxyConfiguration, URLRequest -> the same-named shims; keep Swift's calls and labels. `WKWebView(frame: r, configuration: c)` -> `WKWebView(frame = r, configuration = c)` with a CGRect. `webView.load(URLRequest(url: u))` -> `webView.load(URLRequest(url = u))` (u a java.net.URI or String); `webView.loadHTMLString(s, baseURL: nil)` -> `webView.loadHTMLString(s, baseURL = null)`. `snapshotConfiguration.snapshotWidth = NSNumber(value: x)` -> `= x` (Double?). `configuration.mediaTypesRequiringUserActionForPlayback = []` -> `= emptySet()`. `webView.backgroundColor = .clear` and `webView.scrollView.backgroundColor = .clear` -> `= android.graphics.Color.TRANSPARENT` (Int colours); `isOpaque` and `scrollView.showsVerticalScrollIndicator`/`showsHorizontalScrollIndicator` keep their shape. `webView.estimatedProgress` is a Double in 0...1.
- `userContentController.addUserScript(.init(source: s, injectionTime: .atDocumentStart, forMainFrameOnly: false))` -> `addUserScript(WKUserScript(source = s, injectionTime = WKUserScriptInjectionTime.atDocumentStart, forMainFrameOnly = false))`; `userContentController.add(self, name: n)` -> `add(this, name = n)`. The controller holds handlers weakly, so the owner keeps a strong reference to its handler, as Swift's owners do. A WKScriptMessageHandler implements `override fun userContentController(userContentController: WKUserContentController, didReceive: WKScriptMessage)`; `message.body as? String` -> `didReceive.body as? String`. A `deinit` that only removes script message handlers -> drop it.
- `webView.evaluateJavaScript(js)` -> `webView.evaluateJavaScript(js)` (optional completion `(Any?, Throwable?) -> Unit`). `webView.takeSnapshot(with: c) { image, _ in }` -> `webView.takeSnapshot(with = c) { image, _ -> }`: image is a Bitmap? delivered on main, and `image.cgImage` stays. Create and call WKWebView on the main thread only. `configuration.setHttpProxy(endpoint: e)` and `webView.configuration.setHttpProxy(endpoint: e)` -> `...setHttpProxy(endpoint = e)` (Moblin's extension, import com.moblin.android.various.network.setHttpProxy; e is a com.moblin.android.platform.network.NWEndpoint?).
- BrowserEffect keeps `url: java.net.URI` and `proxyServer`/`setProxyServer(endpoint:)` as `java.net.InetSocketAddress?`; convert with `NWEndpoint.hostPort(NWEndpoint.Host(a.hostString), NWEndpoint.Port(a.port))`. It has no context parameter. `@Published private(set) var layout` -> `val layout = MutableStateFlow<SettingsWidgetLayout?>(null)` and `layout = x` -> `layout.value = x`. `var startLoadingTime = ContinuousClock.now` -> `var startLoadingTime: ContinuousClock.Instant = ContinuousClock.now`. `scale = screenScale()` -> Moblin's `screenScale().toDouble()`.
